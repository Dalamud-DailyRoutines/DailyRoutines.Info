## 본체 변경

- 일부 환경에서 플러그인이 정상적으로 로드되지 않는 문제의 수정을 시도
- `하늘잔 마루 → 울다하 달 회랑` 경로가 잘못된 문제를 수정
- 플러그인 내부에서 지도 표식을 열면 표식에 자동으로 포커스
- 플러그인 리로드 속도를 크게 최적화
    - 모듈 로드/언로드 시 최적의 병렬 구성을 동적으로 계산하도록 변경
    - 다수 모듈의 인스턴스화 시간을 집중적으로 최적화
    - 네트워크 요청을 초기 로드에서 분리
    - 모듈 일괄 로드/언로드를 Framework에서 일괄적으로 분할 실행하여 스레드 전환 감소
- 모듈 목록에 *간이 표시 모드*를 추가합니다. 활성화하면 모든 모듈에 활성화 체크박스, 모듈 제목, 모듈 설명만 표시하고 높이를 항상 한 줄로 유지합니다. 모듈 목록 콘텐츠 영역 오른쪽 위에서 두 모드를 전환할 수 있습니다

![CompactView](/assets/Changelog/2.1.4.0/CompactView.webp)

- 장치 인증 증명서 (TID)가 Wine 환경에서 계속 값을 가져오려 할 수 있던 문제를 수정
- Wine 환경에서는 PC 식별 인증서 (MID)에 Wine 레지스트리의 안정적인 MachineGuid를 사용
- 모든 ToggleButton 스타일을 통일하여 활성화/비활성화 상태가 더 명확하게 보이도록 조정

## 신규 모듈

### 전력 질주 자동 강조 표시 [액션]

*추천 모듈*

임무 입장 후 현재 전투 중이 아니면 "전력 질주" 기술을 자동으로 강조 표시합니다

### *얼어붙은 영혼 자동 사용* [액션]

현재 직업이 "흑마도사"이면 임무 입장, 재도전 발동, 전투 종료 후에 "얼어붙은 영혼"을 자동으로 사용합니다

### *보물지도 위치 자동 표시* [시스템]

보물지도를 해독하거나 사용하면 지도를 자동으로 열고 상세 위치를 표시합니다

### *사용자 지정 지도 표식* [인터페이스]

게임 기본 지도에 사용자 지정 표식을 추가하며 메모, 그룹화, 일괄 가져오기/내보내기 등을 지원합니다

## 모듈 변경

### 플레이어 대상 정보 확장 [인터페이스]

- 플레이어가 장착한 칭호를 표시하는 새 매개변수 `/Title/` 추가

### 자동 로그인 [시스템]

- 데이터센터 내 월드 이동 후 캐릭터가 현재 위치한 월드에서 캐릭터를 검색하여 처리가 실패하던 문제를 수정

### 네트워크 지연 자동 표시 [인터페이스]

- 지연 시간 획득 방식을 최적화하여 더 실제에 가까운 지연 시간을 표시
- 일부 상황에서 패킷 손실률 100%가 계속 반환되던 문제를 수정
- 모듈 로직을 크게 간소화
- Wine 환경에서는 Win32 API를 이용한 RTT 획득을 시도하지 않도록 변경

### 자동 돌발 임무 [전투]

- 모듈 로직을 크게 간소화하고 성능을 향상

### 상태 관련 기술 자동 강조 [액션]

- 모듈 로직을 간소화

### 집사 아이템 간이 입출고 [인터페이스]

- 누락된 로컬라이즈 키를 수정

### 아이템의 NPC 상점 정보를 표시합니다 [인터페이스]

- 목적지 화면 일부 텍스트 노드의 표시 로직을 최적화

### 어디서든 장터 게시판 [인터페이스]

- 월드 선택 컴포넌트에 마우스 오른쪽 클릭으로 현재 월드로 돌아가는 기능 추가

### 주먹치기 자동 플레이 [골드 소서]

- 모듈 로직을 최적화하고 간소화

### 크리스탈 타워 내려치기 자동 플레이 [골드 소서]

- 모듈 로직을 완전히 재구축

### 모그리 뽑기 자동 플레이 [골드 소서]

- 모듈 로직을 완전히 재구축
- 모듈 내부 이름을 변경했으므로 다시 활성화해야 함

### 자동 따라가기 개선 [시스템]

- 모듈 로직을 완전히 재구축
- 따라가기, 중지, 대상 대기 등의 명확한 상태를 추가합니다. 대상이 일시적으로 사라지거나 선택할 수 없을 때 대상이 다시 나타날 때까지 기다린 후 자동으로 따라가기를 재개합니다
- 수동 이동, 기술 사용, 시전, 지역 이동, 컷신 시청 중에는 따라가기를 일시 중지하고 조건이 회복되면 자동으로 재개합니다
- 수동 이동이 끝난 후 잠시 기다렸다가 대상의 최신 위치를 기준으로 다시 길찾기
- 따라가기 거리 완충 구역을 추가하여 임계 거리 부근에서 반복적으로 멈추고 다시 따라가는 문제를 완화
- vnavmesh 따라가기를 최적화하여 근거리 길찾기, 경로 갱신, 정지 확인을 지원하고 길찾기 실패 시 게임 기본 따라가기로 전환
- 오른쪽 클릭 메뉴에 현재 상태에 따라 따라가기 시작, 대상 변경, 따라가기 중지를 표시
- 현재 따라가기를 직접 중지하는 `/pdrfollow stop` 명령어 추가
- 대상과 함께 탈것에 타기, 이륙, 탈것에서 내리기의 실행 로직을 최적화
- 거리 확인 주기가 부정확하거나 대상을 선택할 수 없을 때 따라가기를 반복 재개하던 문제를 수정

### 적대 목록 개선 [전투]

- 상태 효과 컴포넌트 표시 위치를 최적화
