## Core Changes

- Added a convenient teleport route: Foundation ↔ Coerthas Central Highlands.
- Added the "No DR Prefix" setting. When enabled, chat messages sent by the plugin and context menu entries it adds will no longer include the "DR" prefix, blending more naturally with the game's native features, though this may cause confusion. Disabled by default.
- Fixed an issue where the shared teleport logic could not travel from Lower La Noscea to Limsa Lominsa Upper Decks.
- Fixed an issue where ImGui's PopupModal background overlay was drawn in front of the popup window.
- Fixed an issue where the text color of the DRSelectYesno window was displayed incorrectly under non-light themes.
- Submenu entries in context menus now automatically show a "Back" entry.
- Adjusted the appearance of various context menu entries.
- Fixed an issue where item shop information could not be displayed within the Occult Crescent.

## New Modules

### Better Master's Bestiary [Addon]

*Recommended Module*

Improves the "Master's Bestiary" window, allowing you to view detailed information on beasts you have not yet captured and set a beast's size directly from the window.

## Module Changes

### Auto Gather In Diadem [Script]

- Fixed an issue where, in some cases, the character still had not entered Windmire's trigger range or the gathering point's interactable range after pathfinding completed.
- Split the notification messages sent for two different failure cases.
- Relaxed the tolerance for judging a pathfinding route as invalid.
- Fixed an issue where the "Lay of the Land" or "Arbor Call" skill was still used preemptively even though the gathering point information had already been loaded into memory.
- "vnavmesh" is now only invoked to process coordinates when the destination height is uncertain.

### Auto Refresh Market Search Results [Addon]

- The re-request interval changed from a fixed 500 ms to a random interval between 500 ms and 1 second.

### Better Enmity List [Combat]

- Fixed an issue where the cast text background width was calculated incorrectly when "High Resolution UI Settings" was set to anything other than 150%.

### Auto Speed Multiplier [System]

- Adjusted the appearance and content of notification messages.
- Removed the "Send Notification Message" and "Send Chat Message" settings.

### Auto Anti-knockback [Combat]

- Adjusted the appearance and content of notification messages.
- Adjusted the module description.
- Adjusted the appearance of the configuration window.
- Removed the "Send Notification Message" and "Send Chat Message" settings.

### Auto Expert Delivery [Addon]

- The "Ignore Ultimate Raid Items" setting now also detects items related to the "Dancing Mad (Ultimate)" duty (items exchangeable with the "Mad Harlequin's Totem").

### Auto Reuse Emotes [System]

- Fixed an issue where, in rare cases, an "accessing a disposed resource" exception on module unload could crash the game.

### Auto Split Items [System]

- Adjusted the window text.
- Adjusted the appearance of notification messages.
- The per-stack quantity input window shown after splitting is now drawn with the game's native UI instead of ImGui.
- Greatly improved splitting speed.

### Player Right-click Search [Addon]

- Removed the "SuMemo" platform.
- Added the "Universalis" and "TeamCraft" platforms.
- Adjusted the appearance of notification messages.
- Adjusted the window text.
- When visiting "Lodestone" or "FF Logs", the plugin now automatically routes to the language-specific page offered by each platform according to the client language.
- When visiting "Lodestone", "Tomestone", or "Lalachievements", the plugin now opens the character information window directly once the corresponding player information is found.
- Changed the appearance of the "Search All" menu entry to emphasize it further and avoid confusion.
- The "Search All" menu entry is now shown only when more than two platforms are enabled.
- Certain platforms are now shown or hidden in the menu based on the current item's information.
※ For example, even if the "Universalis" platform is enabled, it will not appear in the menu if the item itself cannot be traded on the market board.
