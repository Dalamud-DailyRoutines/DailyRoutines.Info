## 본체 변경

- 일부 백그라운드 작업의 성능 소모를 최적화했습니다.
- 도시 내 이동으로 도달할 수 있는 야외 지역에서 도시 내 이동이 있는 마을 지역으로 텔레포트할 때, 도시 내 이동 사용을 시도해 흐름이 멈추던 문제를 수정했습니다.
- 에테라이트 사용 시 항상 1초가 지연되던 문제를 수정했습니다.
- 일부 도시 내 에테라이트를 사용하면 잘못된 도시 내 에테라이트로 이동되던 문제를 수정했습니다.
- '최소한의 길을 소모하여 다른 지역으로 이동합니다.' 설정이 비활성화된 경우 2홉 이상 경로의 패널티를 더욱 높여 편의성을 유지하면서 가능한 한 직접 텔레포트하도록 했습니다.
- Universalis 요청 로직을 최적화했습니다.
- 일부 네이티브 UI 로딩 시 게임이 크래시되던 문제를 수정했습니다.

## 신규 모듈

### *'영구 초토지대' 도우미* [콘텐츠]

*추천 모듈*

'영구 초토지대'의 마지막 보스 '안개 드래곤'이 '기화' 상태일때,  자동으로 타겟팅하거나 공격하는 것을 방지합니다.

## 모듈 변경

### '초승달 섬' 도우미 [콘텐츠]

- 설정 화면의 렌더링 로직을 완전히 재구성했습니다.
    - 모든 탭을 내부에서 다시 탭으로 나누어 기존에 지나치게 잘게 쪼개져 있던 화면 구성을 대체했습니다.
    - '보물 상자' 탭의 '원래 위치로 돌아가기' 버튼에 명확한 화면 텍스트를 표시합니다.
    - '보물 찾기' 기능이 그리는 지도를 최적화했습니다.
        - 지도를 화면 왼쪽 위에 고정 표시합니다.
        - 경유 지점과 경로를 굵게 표시합니다.
        - 플레이어를 나타내는 표식을 삼각형으로 변경하여 현재 바라보는 방향을 표시합니다.
    - 보물 찾기 경로 버튼 위에 마우스를 올리면 지도가 자동으로 표시되며 해당 경로가 강조됩니다. 경로는 플레이어의 현재 위치를 기준으로 실시간 생성됩니다.
- 모듈이 비활성화된 상태에서의 인스턴스화 성능을 최적화했습니다.
- 보물 찾기 기능을 완전히 재구성했습니다.
    - 캐릭터가 항상 지표면 아래에 머물며 게임 내 지형의 기복을 따라가지 않습니다.
    - 경로 하나를 완료하면 먼저 탈것에서 내린 후 데미 데존을 사용합니다.
    - 보물 찾기 경로를 다시 제작했습니다.
        - 북부편: 내부 루프(총 30개 지점), 외부 루프(총 38개 지점)
        - 남부편: 내부 루프(총 23개 지점), 외부 루프(총 45개 지점)
- '플러그인 자동 활성화/비활성화' 설정을 제거하고 새로운 '임무 입장 시 실행할 명령어'와 '임무 퇴장 시 실행할 명령어'로 분리하여 더욱 개인화된 요구에 대응합니다.
    - 해당 기능의 상위 스위치도 함께 제거했습니다. 필요 없다면 두 입력란을 모두 비워 두면 됩니다.
- `/pdr ptp` 명령어가 '초승달 섬: 북부편'에서 작동하지 않던 문제를 수정했습니다.
- `/pdr ptp`에 잘못된 인덱스를 전달하면 예외가 발생하던 문제를 수정했습니다.
- 길찾기 기능을 조정했습니다.
    - 마도 통로 상호작용 범위 밖이자 vnavmesh 종점 허용 범위 안에서 길찾기를 시작하면 흐름이 멈추던 문제를 수정했습니다.
    - 마도 통로에 비교적 가까울 때 도보로 접근하지 않고 탈것에 타던 문제를 수정했습니다.
    - 사용 가능한 마도 통로를 계산할 때 vnavmesh를 호출해 경로 길이를 비교합니다.
    - 돌발임무로 길찾기 시 범위 내 임의의 위치를 무작위로 선택하던 방식을 제거했습니다.
    - 돌발 임무로 길찾기 시 몬스터 정보를 자동으로 가져와 길찾기 종점을 조정하고 몬스터를 선택하려 시도합니다.
    - 길찾기 과정의 성능 소모를 줄였습니다.

### 자동 돌발 임무 [스크립트]

- '아이템' 모드를 완전히 재구성하고 이름을 '사용자 지정'으로 변경했습니다.
    - 외형 스타일과 상호작용 로직을 재구성하고 좌우 분할 레이아웃을 채택했습니다.
    - 각 지역에서 최소한으로 완료해야 하는 돌발 임무 횟수를 설정할 수 있습니다.
    - 지역 진입 시 소환할 꼬마 친구를 설정할 수 있습니다.
    - 지역 진입 시 실행할 매크로를 설정할 수 있습니다.
    - 기본 프리셋을 사용자 지정 프리셋으로 복사할 수 있습니다.
- 사용자 지정 모드에 기본 프리셋을 추가했습니다.
    - 팬텀 웨폰+2
    - 팬텀 웨폰+4
    - 요괴메달
    - 레전드 요괴메달
- 돌발 임무 범위에 진입하면 먼저 아무 돌발 임무 몬스터에게 접근하고, 발밑에 유효한 지면이 있을 때 탈것에서 내리도록 변경했습니다.

### 초상화 모션 프레임 단위 편집 [인터페이스]

- 게임 네이티브 UI로 모듈을 완전히 재구성해 전체 구현을 더 간결하게 만들었습니다.
    - 프레임 단위로 조정하도록 변경하고 '반올림', '+10', '-10' 버튼을 제거했습니다. 기존 '+1', '-1' 버튼은 정수가 아닌 프레임에서 클릭하면 먼저 정수 프레임으로 반올림됩니다.

### 아이템 자동 폐기/판매 [시스템]

- 우클릭 메뉴에 '자동 버리기 설정 그룹에 추가'를 추가하여 아이템을 지정한 설정 그룹에 빠르게 추가할 수 있습니다.

### 주변 플레이어 자동 표시 [일반]

- '현재 지역 플레이어' 데이터 획득 간격을 10초에서 60초로 늘렸습니다.
- 지역 전환 시 즉시 지역 내 플레이어 데이터를 한 번 가져오려 시도합니다.

### 자동 플레이어 추천 [콘텐츠]

- 우클릭 메뉴로 플레이어를 지정하면 알림 메시지 대신 채팅 메시지를 보냅니다.
- 자신을 선택했을 때 표시되는 우클릭 메뉴 항목이 올바르게 '최적의 소대원을 자동으로 추천하지 않습니다.'로 표시됩니다.
- 각 알림 문구의 내용을 조정했습니다.

### 집사 수행 자동화 [인터페이스]

- 현지화 처리되지 않았던 각 열거값을 보완했습니다.

### 채집가 능력 스킬 자동 사용 [제작 및 채집]

- 홈 월드에 있지 않을 때도 '숲의 탐구자'와 '광산의 탐구자'를 사용하려 시도하던 문제를 수정했습니다.

### 자동 아이템 분해 [인터페이스]

- 인터페이스 닫기 버튼을 가리던 문제를 수정했습니다.

### 게임 오브젝트 스케일 조정 [시스템]

- 'Mount Object ID'의 구체적인 값이 표시되지 않던 문제를 수정했습니다.

### 로그아웃 조작시 쿨다운 잠금 해제 [시스템]

- 게임 버전 7.55 이후 로그인 대기열 대화상자의 갱신 효과음을 올바르게 차단하지 못하던 문제를 수정했습니다.
