- Improved the issue where connecting to the online verification service was difficult in IPv6 network environments.

### Notice Regarding the Centralized Adjustment of Notification Features

(The following changes may take several versions to be fully adjusted.)

- As the "text-to-speech" feature has been separated into the standalone `EdgeTTS.Dalamud` plugin, and that feature feels quite intrusive in practice, the message content of a tray notification will now only be read aloud when a "Windows tray notification" is sent and that plugin is detected as enabled.
- "Chat message" type notifications will be divided into two kinds.
    - With the "DR" prefix: notifications whose content could clearly only be produced by features provided by the plugin.
      Examples: a notification whose content is "batch crafting complete"; a notification whose content is "an item's market price fell below the configured value"; a notification whose content is "all submersibles have returned" but which can be interacted with to travel and collect automatically.
    - Without the "DR" prefix: notifications whose content the game itself can also produce, and which merely are not displayed or not explicitly notified.
      Examples: a notification whose content is "entered a movement speed detection area"; a notification whose content is "successfully logged in to the game"; a notification whose content is "knockback effect incurred".
- Except for "chat message" type notifications, no other type of notification contains the "DR" prefix.
- The sending channel for "chat message" type notifications will change from "Debug" to "System Messages". From now on, you can filter these messages by unchecking "System Messages" under the "Notification" tab in the "Log Filters" window. (Not all "chat message" type notifications are sent through the "System Messages" channel.)
- "Dalamud notification" type notifications will be used only for feedback produced when operating interfaces drawn with ImGui.
- "Chat message" type notifications will instead be concentrated on feedback produced when operating the game's native interfaces (including native-style interfaces made by the plugin) and native system mechanics.
- "Duty mechanic" type notifications are used only for the very few pieces of feedback that require special emphasis (including entertainment-type ones announced in advance).
- "Windows tray notification" type notifications will be used for long-running automation or particularly urgent cases, including those requiring background notification. Such notifications are also sent only when the game is in the background or when the game has not received any key input for 15 seconds. Generally, other types of notifications also send the same content.
- The applicable situations for "floating toast" type notifications are broadly the same as those for "chat message" type notifications, but their specific use heavily references and mimics how similar native game system mechanics are used, so as to resemble native mechanics more closely.
- "Windows system sound" type notifications (including buzzer) are used only for the very few pieces of feedback that require special emphasis (including entertainment-type ones announced in advance).

## New Modules

### Auto Resume New Game+ [System]

Automatically continue progress of New Game+ after logging in or leaving a duty if there is suspended progress available.

### Unrestricted Macro Icon [Addon]

*Recommended*

Allow to assign any icon to a macro using the command /pdr micon <icon ID>.

### Better Desynthesis [Addon]

*Recommended*

Provide a better Desynthesis interface, including desynthesis information, desynthesis skill information, batch desynthesis and auto confirmation while desynthesizing manually.

## Removed Modules

### Auto Item Desynthesis [Addon]

Due to the feature migration, please use the new module "Better Desynthesis".

### Auto Notify Special Players Appearance [Notification]

Because the implementation is too outdated and difficult to maintain, its practical use is unclear, and the feature can be replaced by other modules and plugins, it has been removed.
