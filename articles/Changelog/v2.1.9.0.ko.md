## 본체 변경 사항

- 편리한 텔레포 경로를 추가했습니다: 이슈가르드 하층 ↔ 커르다스 중앙고지.
- 설정 항목 ‘DR 접두사 표시 안 함’을 추가했습니다. 활성화하면 플러그인이 보내는 채팅 메시지와 추가하는 우클릭 메뉴 항목에 ‘DR’ 접두사가 더 이상 포함되지 않아 게임 기본 기능과 더 자연스럽게 어울리지만, 혼동을 줄 수 있습니다. 기본값은 비활성화입니다.
- 공유 텔레포 로직으로 저지 라노시아에서 림사 로민사 상층 갑판으로 이동할 수 없던 문제를 수정했습니다.
- ImGui의 PopupModal 배경 오버레이가 팝업 창보다 앞에 그려지던 문제를 수정했습니다.
- DRSelectYesno 인터페이스 텍스트 색상이 밝은 테마가 아닐 때 비정상적으로 표시되던 문제를 수정했습니다.
- 우클릭 메뉴의 하위 메뉴 항목에서 ‘뒤로’ 항목이 자동으로 표시되도록 지원합니다.
- 각 우클릭 메뉴 항목의 외형 스타일을 조정했습니다.
- ‘초승달 섬’ 내 아이템 상점 정보를 표시할 수 없던 문제를 수정했습니다.

## 모듈 변경 사항

### 디아뎀 제도 자동 채집 [스크립트]

- 일부 상황에서 경로 탐색이 끝난 뒤에도 용올림 발동 범위나 채집 포인트 상호작용 범위에 들어가지 못하던 문제를 수정했습니다.
- 서로 다른 두 가지 오류 상황에서 전송하는 알림 메시지를 분리했습니다.
- 경로 탐색 경로를 무효로 판정하는 범위 허용치를 완화했습니다.
- 채집 포인트 정보가 이미 메모리에 로드되었는데도 ‘바위의 부름’ 또는 ‘숲의 부름’ 스킬을 먼저 사용하던 문제를 수정했습니다.
- 이제 목적지 높이가 불확실할 때만 ‘vnavmesh’를 호출하여 좌표를 처리합니다.

### 장터 게시판 검색 결과 자동 새로고침 [인터페이스]

- 재요청 간격을 고정 500밀리초에서 500밀리초~1초 사이의 무작위로 변경했습니다.

### 적대 목록 개선 [전투]

- ‘고해상도 UI 크기 설정’이 150%가 아닐 때 시전 텍스트 배경 너비 계산이 비정상적이던 문제를 수정했습니다.

### 이동 속도 조정 [시스템]

- 알림 메시지의 외형 스타일과 내용을 조정했습니다.
- 설정 항목 ‘알림 메시지 전송’과 ‘채팅 메시지 전송’을 제거했습니다.

### 넉백 동작 변경 [전투]

- 알림 메시지의 외형 스타일과 내용을 조정했습니다.
- 모듈 설명을 조정했습니다.
- 설정 인터페이스의 외형 스타일을 조정했습니다.
- 설정 항목 ‘알림 메시지 전송’과 ‘채팅 메시지 전송’을 제거했습니다.

### 희귀품 조달 자동화 [인터페이스]

- 설정 항목 ‘절 난이도 관련 장비 제외’에 ‘절 요성난무’ 콘텐츠 관련 장비(‘광대의 우상’으로 교환할 수 있는 장비) 감지를 추가했습니다.

### 감정 표현 자동 재사용 [시스템]

- 극히 드물게 모듈 언로드 시 ‘해제된 리소스 접근’ 예외가 발생하여 게임이 충돌하던 문제를 수정했습니다.

### 아이템 자동 분할 [시스템]

- 인터페이스 텍스트 내용을 조정했습니다.
- 알림 메시지의 외형 스타일을 조정했습니다.
- 분할 후 묶음당 수량 입력 인터페이스의 그리기 방식을 ImGui에서 게임 기본으로 변경했습니다.
- 분할 속도를 대폭 향상했습니다.

### 플레이어 우클릭 메뉴 확장 [인터페이스]

- ‘SuMemo’ 플랫폼을 제거했습니다.
- ‘Universalis’와 ‘TeamCraft’ 플랫폼을 추가했습니다.
- 알림 메시지의 외형 스타일을 조정했습니다.
- 인터페이스 텍스트 내용을 조정했습니다.
- ‘Lodestone’ 또는 ‘FF Logs’ 플랫폼에 접속할 때 클라이언트 언어에 따라 각 플랫폼이 제공하는 언어별 페이지로 자동 분기합니다.
- ‘Lodestone’, ‘Tomestone’, ‘Lalachievements’ 플랫폼에 접속할 때 해당 플레이어 정보를 검색하면 곧바로 캐릭터 정보 화면을 엽니다.
- ‘모든 플랫폼에서 검색’ 메뉴 항목의 외형 스타일을 변경하여 혼동을 피하도록 더욱 강조했습니다.
- 이제 활성화된 플랫폼이 세 개 이상일 때만 ‘모든 플랫폼에서 검색’ 메뉴 항목을 표시합니다.
- 현재 아이템 정보에 따라 메뉴에서 일부 플랫폼을 표시하거나 숨깁니다.
※ 예를 들어 ‘Universalis’ 플랫폼을 활성화했더라도 해당 아이템 자체가 장터에서 거래할 수 없다면 메뉴에 해당 플랫폼이 표시되지 않습니다.

### 어디서든 장터 게시판 [인터페이스]

- 우클릭 메뉴 항목 텍스트를 조정했습니다.

### 우클릭 메뉴에 아이템명 복사 추가 [시스템]

- 모듈 설명 텍스트를 조정했습니다.

### * 아이템 상점 정보 자동 표시 [시스템]

- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- 인터페이스의 외형 스타일을 조정하고, 비플레이어 오브젝트에 전체 오브젝트 이름을 표시하는 텍스트 호버 힌트를 추가했습니다.
- ‘아이템 정보창’의 표시 텍스트를 조정하고, 이제 상점 판매 정보를 최대 다섯 건까지 표시합니다.
- 알림 메시지 텍스트와 외형 스타일을 조정했습니다.

### * 아이템 일괄 사용 [시스템]

- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 모듈 이름 텍스트를 조정했습니다.
- 아이템을 연속 사용하는 로직을 최적화하여 전체 흐름을 더 매끄럽게 만들었습니다.
- 메뉴 항목 ‘일괄 사용’을 사용할 때 항상 모든 아이템을 사용하는 로직에서 먼저 사용 횟수를 입력받는 방식으로 변경했습니다. 횟수의 기본값은 해당 아이템의 현재 수량입니다.
- 일괄 사용이 완료되면 알림 메시지를 전송합니다.

### * 소환수 체형 우클릭 메뉴 [인터페이스]

- 모듈 이름 텍스트를 조정했습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- ‘맹수 조련사’가 소환하는 마수의 표시 크기를 설정할 수 있습니다.
- 소환수/마수를 소환한 상태라면 자신의 우클릭 메뉴에 ‘소환수 외형 설정’/‘마수 외형 설정’ 항목을 추가합니다.
- 현재 직업이 ‘비술사’, ‘소환사’, ‘맹수 조련사’일 때만 관련 우클릭 메뉴 항목을 추가합니다.

### 지도 링크 자동 열기 [시스템]

- 인터페이스 텍스트를 조정했습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- 설정 항목 ‘마크만 하고 지도는 새로고침하지 않기’를 제거했습니다.
- 설정 항목 ‘지도 자동 열기’를 추가했습니다. 활성화하면 지도에 마크하는 동시에 지도를 엽니다. 기본값은 활성화입니다.
- 이제 플레이어를 구독하거나 구독 취소할 때 작업 성공 여부를 알리는 알림 메시지를 전송합니다.
- 설정 인터페이스에서는 플레이어를 구독하거나 구독 취소할 수 없으며, 우클릭 메뉴에서만 조작할 수 있습니다.
- 선택할 수 있는 메시지 채널을 더욱 제한했습니다.

### 자동 따라가기 개선 [시스템]

- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 알림 메시지 텍스트와 외형 스타일을 조정했습니다.
- 수동 이동이나 스킬 사용 후 따라가기를 다시 시작하기까지의 대기 시간을 1000밀리초에서 100밀리초로 단축했습니다.
- 대상 상실 상태가 아닐 때의 따라가기 판정 갱신 간격을 250밀리초에서 50밀리초로 단축했습니다.

### 차단 목록 개편 [시스템]

- 알림 메시지 텍스트를 조정했습니다.
- 우클릭 메뉴 항목에서 이미 해당 플레이어가 존재하는 로컬/공유 차단 목록을 자동으로 비활성화합니다.
- 모듈 언로드 시 관련 네트워크 요청이 취소되지 않던 문제를 수정했습니다.
- 일부 공유 차단 목록 관련 알림 정보에 차단 목록 이름이 아닌 ID가 표시되던 문제를 수정했습니다.
- 설정 인터페이스에서 Content ID로 플레이어를 추가할 때 입력 완료 후 CID 유효성을 검증합니다.

### 친구 목록 개선 [인터페이스]

- 우클릭 메뉴 텍스트를 조정했습니다.
- ‘이전 이름 조회’ 기능을 ‘친구 이름과 코멘트’ 인터페이스에서 우클릭 메뉴 항목으로 옮겼습니다.
- 모듈 언로드 시 이전 이름 요청이 취소되지 않던 문제를 수정했습니다.
- 이전 이름을 표시하는 전용 기본 인터페이스를 추가했습니다.

### 추가 메시지 필터 프리셋 [인터페이스]

- 우클릭 메뉴 항목 텍스트를 조정했습니다.
- 설정 인터페이스에서 프리셋을 적용할 수 없으며, 우클릭 메뉴 항목으로만 조작할 수 있습니다.
- 설정 인터페이스에서 프리셋 상세 정보를 확인할 수 있습니다.
- 저장한 프리셋은 미리 특정 메시지 창을 지정하지 않아도 사용할 수 있으며, 이제 어떤 프리셋이든 우클릭 메뉴를 통해 임의의 메시지 창에 적용할 수 있습니다.
- 이제 설정 인터페이스에서 프리셋을 삭제하려면 버튼을 길게 눌러야 하므로 실수를 방지할 수 있습니다.

### 잠수함 재료 자동 회수 [인터페이스]

- 알림 메시지 텍스트와 외형 스타일을 조정했습니다.
- 인터페이스 텍스트를 조정했습니다.
- 설정 항목 ‘로그인 시 잠수함 탐사 결과 채팅 메시지 전송’을 제거하고, 이제 로그인 시 항상 잠수함 정보를 요청합니다.
- 이제 현재 계정이 부대에 가입되어 있고 콘텐츠 안이 아닐 때만 잠수함 정보를 요청합니다.
- 잠수함이 모두 귀환하지 않았을 때의 알림 메시지 전송 간격을 10분에서 4시간으로 변경했습니다.

### 지역 내 맵 전환 로딩 가속 [시스템]

- 더 저수준의 구현 방식을 채택하여 지역 로딩 완료 속도를 더욱 크게 향상했습니다.
- ‘로딩 시 UI 페이드 없음’을 전제 모듈에서 추천 모듈로 변경했습니다.
- 설정 항목 ‘로컬 이동 제한만 해제’를 제거했습니다.
