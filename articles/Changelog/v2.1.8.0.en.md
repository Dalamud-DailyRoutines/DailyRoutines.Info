## Core Changes

- Greatly improved the experience of accessing Universalis services from networks outside the Chinese Mainland.
- The base-10000 number formatting feature now supports Korean.
- Fixed an issue where the shared movement logic would try to use a non-existent zone line in certain areas.

## New Modules

### Teleportable Aethernet On Map [Addon]

*Recommended Module*

Allow to directly teleport to an aethernet shard by clicking it on the map, like how aetherytes work.

### Auto Game Config Backup [System]

Automatically synchronize the game configuration to GitHub Gist while logging in after proper configurations. The feature comes with conflict detection and recovery from the cloud.

## Module Changes

### Better Letters [Addon]

- Fixed an issue where button texts were duplicated.
- Completely rewrote the logic of the "Claim Letters" and "Delete Letters" features, now using deeper-level invocation points, greatly improving operation speed.
- Changed the "Claim All" button to be triggered by a long press to avoid accidental touches.
- Clicking the "Reward Delivery Request" button modified by the module will now send a notification message to indicate that the click took effect.

### Auto Aetheric Mimicry [Action]

- Fixed an issue where some areas of the window could not be clicked.
- Added a window title to indicate the purpose of the window more clearly.
- Improved the appearance of the window buttons, making them larger and adding a clear Blue Mage icon.
- Adjusted the appearance style of notification messages.

### Better World Visit [System]

- Adjusted the appearance style of notification messages.
- Enabling the "World Visit shortcut in Server Info Bar" setting now automatically disables the game's "Display current World name." setting.

### Real-time Network Metrics [Addon]

- Added localized text for the metric labels in the window.
- Enlarged the font size of the metric values in the window.
- To keep it concise, the default format text of the server info bar entry no longer includes the "Delay: " part; it will now display text like "90 ms".

### Auto Prevent Duplicate Actions [Action]

- Removed the support-role mage action "Occult Mage Masher".

### Better Market Board [Addon]

- Completely reworked the window's appearance and interaction logic design.

![BetterMarketBoard-UI](/assets/Changelog/2.1.8.0/BetterMarketBoard-UI.png)

- Further restricted the timing of when market data for the current world can be searched, avoiding unintended data packets being sent.
- Fixed an issue where clicking the "Reload Market Data" button could permanently hide the world selector when the selected world is in a different region from the current world.
- Removed the mechanism that automatically cleared market data and the selected item information when switching regions.
- Fixed an issue where data was not refreshed in time when switching worlds.
- Moved the price monitoring feature entirely from the settings window into the main window.
- Moved the option for distinguishing HQ from the auto-purchase sub-feature into the price monitoring feature.
- Removed the test-code requirement of the "Auto Purchase" feature.
- Adjusted the appearance style of notification messages.
- Changed the "Auto Refresh Market Search Results" module from a prerequisite module to a recommended module.
- Fixed the `/pdr market` command help text not mentioning that arguments can be passed.
- Blocked the issue that could allow purchasing items sold by one's own retainers in some cases.

### Auto Refresh Market Search Results [Addon]

- Removed the IPC `DailyRoutines.Modules.AutoRefreshMarketSearchResult.IsMarketStuck`.
- Greatly simplified the logic.

### Auto Retainer Routines [Addon]

- Added the prerequisite module "Better Market Board".
    - Market data requests and display logic are all handled by that prerequisite module, so without enabling it, the "Auto Adjust Asking Price" feature will not work properly.

### More Macro Parameters [System]

- Adjusted the logic for determining whether a target is hostile.

### Better BLU Active Set [System]

- Changed the category from "Addon" to "System".
- Completely rewrote the logic, using a more low-level implementation that covers more scenarios.
- Adjusted the appearance style of notification messages.
- Fixed an issue where command registrations were not cleaned up on unload.

### Auto Reveal Treasure Location [System]

- When displaying the treasure map location, the name of the treasure map will also be displayed at the top of the map window.
