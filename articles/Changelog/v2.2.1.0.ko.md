## 본체 변경 사항

- 수명 주기 내에서 '장치 인증 증명서' 획득에 실패한 뒤 다시 획득을 시도하지 않던 문제를 수정했습니다.
- '장치 인증 증명서' 획득 실패 시 로그 출력을 추가했습니다.
- '장치 인증 증명서'가 프로세스 간에 동일한 임시 파일을 사용하여 실패하던 문제를 수정했습니다.
- '계정 인증 증명서' 생성 시점을 최적화하여, 캐릭터가 완전히 로그인할 필요가 없어졌습니다.
- 공유 지역 이동 과정에서 * 인스턴스 구역 선택 단계에서 멈출 수 있던 문제를 수정했습니다.
- 공유 지역 이동 과정에서 전송을 직접 중단하면 이동 요청을 다시 보낼 수 없던 문제를 수정했습니다.
- 일부 필드가 남아 로드 컨텍스트를 언로드할 수 없게 되어, 플러그인 재로드나 모듈 재로드 시 메모리가 누수되던 문제를 수정했습니다.

## 신규 모듈

### * 간이 채집 자동 활성화 [제작 및 채집]

*오늘의 추천 모듈*

* 채집 창이 나타나면 '간이 채집하기'를 자동으로 체크합니다.

### * '/중요 아이템' 명령어 개선 [시스템]

*오늘의 추천 모듈*

* '/중요 아이템(/collection, /coll)' 명령어에서 중요 아이템 이름을 입력하여 해당 화면을 바로 열 수 있도록 합니다.
(예: /coll 모그모그 안내서, /collection 추억의 견문록)

### * 퀘스트 대상 자동 표시 [인터페이스]

* 진행 중인 퀘스트의 대상 오브젝트를 주변에 자동으로 표시하여 쉽게 찾을 수 있도록 합니다.

## 모듈 변경 사항

### 주변 오브젝트 빠른 조사 [인터페이스]

- 오버레이 오른쪽의 '* 인스턴스 구역', '도시 내 에테라이트', '서버 텔레포' 컴포넌트를 펼치거나 접을 수 있어 인터페이스가 길어지는 것을 방지합니다.

### 빠른 전송 패널 [인터페이스]

- 해제된 메모리를 읽어 간헐적으로 게임이 충돌하던 문제를 수정했습니다.
- 일부 퀘스트의 아이콘을 읽지 못해 데이터 새로고침이 실패하던 문제를 수정했습니다.
- 전체 설계 로직을 재구성하여 성능을 향상시켰습니다.

### 퀘스트 전투 매우 쉬움 설정 [콘텐츠]

- 알림 전송 판단 시점을 조정했습니다.

### 대상 표식 자동 조정 [전투]

- 더 이상 '오늘의 추천 모듈'이 아닙니다.
- 일부 표식의 크기와 위치를 설정할 수 없거나 곧바로 원래대로 돌아가던 문제를 수정했습니다.

### 중첩 아이템 자동 사용 [시스템]

- 네트워크가 불안정한 상황에서 과정이 멈추던 문제를 수정했습니다.
- 과정 로그를 출력합니다.

### 빠른 날씨 및 시간 설정 [인터페이스]

- 시간과 날씨를 복원할 때 게임이 충돌할 수 있던 문제를 수정했습니다.

### 주변 플레이어 자동 표시 [일반]

- 지역 플레이어 요청 전송 시점을 늦추어, 지역을 너무 빠르게 전환할 때 잘못된 요청을 보내지 않도록 했습니다.

### FPS 제한 설정 개선 [시스템]

- 설정한 프레임 수가 평균 프레임보다 높을 때 프레임 수가 떨어지던 문제를 수정했습니다.

### 마우스 자동 하이라이트 표시 [인터페이스]

- 더 이상 '오늘의 추천 모듈'이 아닙니다.

### 자동으로 로컬 플레이어의 판정 지점 표시 [전투]

- 더 이상 '오늘의 추천 모듈'이 아닙니다.

### 어디서든 장터 게시판 [인터페이스]

- '길게 눌러 일괄 구매' 버튼의 조작 시간을 2초에서 1초로 단축했습니다.
- 일괄 구매 후 장터 데이터가 표시되지 않던 문제를 수정했습니다.
- 일부 아이템의 장터 데이터에 '마네킹' 열이 잘못 표시되던 문제를 수정했습니다.

### 친구 목록 개선 [인터페이스]

- '친구 닉네임 및 비고' 인터페이스의 외형 스타일과 조작 로직을 재구성했습니다. 주요 변경 내용은 다음과 같습니다:
    - '지우기' 버튼에 재확인 절차를 추가했습니다.
- '이전 이름 목록'과 '검색 설정' 인터페이스의 조작이 '친구 목록' 인터페이스로 전달되지 않습니다.
- 다른 데이터 센터의 친구도 우클릭 메뉴 '* 닉네임 및 비고 수정'과 '이전 닉네임 조회'를 표시할 수 있습니다.

### 장터 게시판 검색 결과 자동 새로고침 [시스템]

- 분류를 '인터페이스'에서 '시스템'으로 변경했습니다.

### 텔레포 UI 최적화 [인터페이스]

- 에테라이트/도시 내 에테라이트가 목록에 표시될 때 해당 지역 아이콘이 함께 표시됩니다.
- 전체 에테라이트 목록 인터페이스의 페이지 머리글이 버전 아이콘으로 표시됩니다.

### 부대원 관리 패널 [인터페이스]

- 모듈 구현 로직을 전면적으로 재구성하여 모든 일괄 작업을 저수준 게임 함수로 변경하고 조작 효율을 크게 향상시켰습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 인터페이스의 외형 스타일을 개선했습니다.
- 부대원의 마지막 로그인 시간이 표시되지 않던 문제를 수정했습니다.
- 인터페이스 목록에 '* 계급' 열을 추가했습니다.
- 부대원 제명에 재확인 절차를 추가했습니다.
- 잘못 선택하는 것을 막기 위해 목록에 자신을 표시하지 않습니다.
- 이름 검색 기능을 머리글에서 최상위로 이동했습니다.
- '* 계급' 목록 머리글을 우클릭하여 특정 계급의 부대원을 필터링할 수 있습니다.
- '위치 / 마지막 로그인 시간' 목록 머리글을 우클릭하여 마지막 로그인 시간으로 부대원을 필터링할 수 있습니다.
- 이제 '자유부대 부대원' 인터페이스를 닫으면 모듈 인터페이스도 함께 닫힙니다.

### 빠른 서버 텔레포 명령어 [인터페이스]

- (중국 서버 한정) '* 통행 상태 모니터링' 기능을 제거했습니다.

### 제작 수첩 UI 최적화 [제작 및 채집]

- 분류를 `인터페이스`에서 `제작 및 채집`으로 변경했습니다.
- 알림 메시지의 외형 스타일을 조정했습니다.
- '제작 절차' 인터페이스를 여는 로직을 개선했습니다.
- '제작 절차' 인터페이스의 외형 스타일과 조작 로직을 전면적으로 재구성했습니다.

![OptimizedRecipeNote-Addon](/assets/Changelog/2.2.1.0/OptimizedRecipeNote-Addon.png)

- 일괄 제작 상한을 99999회로 고정했습니다.
- 자동 제작 중 '제작 절차' 인터페이스의 기술 아이콘이 사용 완료 후에야 어두워집니다.
- 인터페이스 요소 위치 변경이 인터페이스를 열 때 즉시 적용되지 않던 문제를 수정했습니다.

### 적대 목록 개선 [전투]

- 시전 진행 컴포넌트의 외형 스타일을 조정했습니다.
- 시전 텍스트와 체력 텍스트의 기본 외곽선 색상을 조정하여 기본 인터페이스와 일치시켰습니다.
- 중단 가능한 기술의 시전 텍스트에도 경고를 위해 빨간 외곽선을 표시합니다.

### 무인도 자동 채집 [스크립트]

- 무인도 밖에서도 알림 메시지가 전송될 수 있던 문제를 수정했습니다.

### 집사 수행 자동화 [인터페이스]

- ImGui로 그린 오버레이가 기본 인터페이스를 가리지 않으며, 기존 오버레이의 대부분 기능은 우클릭 메뉴나 기본 스타일 인터페이스로 제공됩니다.
- 설정 항목 '* 출품 시 가격 자동 변경'의 동작을 변경했습니다. 기본 '출품 정보 변경' 인터페이스는 계속 표시되지만, 그 안에서 가격은 조정할 수 없고 판매 수량만 조정할 수 있습니다. 그 안에서 확인을 누른 뒤에야 시세를 자동으로 조회하고 규칙에 따라 판매 가격을 조정하기 시작합니다.
- 기본 '시세 보기' 버튼이 '어디서든 장터 게시판' 모듈 인터페이스를 여는 것으로 변경되었습니다.

### 즉시 다른 파티 참가 [인터페이스]

- 버튼 클릭에 재확인 절차를 추가했습니다.
- 인터페이스를 열 때 버튼이 바로 표시되지 않던 문제를 수정했습니다.
