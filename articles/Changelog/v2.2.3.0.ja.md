## 本体の変更

- Wine 環境の検出方法を最適化しました。
- 「デバイス認証情報」に関連する認証取得コンポーネントを更新しました。
- オンライン認証の接続でシステムプロキシを必ず迂回させる仕組みを削除しました。
- 初期化読み込みの優先度を高めました。
- 更新履歴画面で長すぎる画像が表示領域からはみ出す問題を修正しました。
- 「全般」に設定項目「オンライン認証時にシステムのプロキシ設定を無視させる」を追加しました。オンライン認証のリクエスト送信時にシステムプロキシ設定を無視し、認証サーバーへ直接接続します。仮想ネットワークアダプタなどの全体的な透過プロキシを使用している場合、本項目は機能しません。既定では無効で、以前のバージョンと同じ挙動です。
- 「全般」に設定項目「アクティブ状態での無操作通知表示時間（ミリ秒）」を追加しました。無操作の時間が設定値に達すると、ゲームがアクティブ状態であっても Windows のトレイ通知を表示します。0 に設定すると、ゲームがバックグラウンドにあるときのみ通知します。既定値は 15000 ミリ秒で、以前のバージョンと同じ挙動です。
- 右クリックメニューの解析が「アイテム検索」画面に対応しました。
- 「全般」の設定項目「割り込みホットキー」のヘルプテキストを調整しました。
- 「割り込みホットキー」の表示は、現在のゲーム操作モードに応じてキーボードのキーまたはゲームパッドのキーの設定値をそれぞれ表示します。
- デバッグ画面がキャッシュモジュールを速やかに破棄しなかったため、「モジュールの再読み込み」で古いモジュールインスタンスを解放できなくなる問題を修正しました。
- JSON コンバーターが速やかに破棄されず、アセンブリを解放できなくなる問題を修正しました。
- Newtonsoft.Json がキーと値のペアのシリアル化で動的メソッド参照を生成し、アセンブリを解放できなくなる問題を修正しました。
- 「モジュールの再読み込み」のたびに完全なガベージコレクションを実行するようにしました。
- ネイティブ画面の周囲に付着するすべての画面の実装を全面的に作り直しました。現在はゲームのネイティブな子画面システムのみで実装しています。実装方法が異なるため、外観と操作方法も以前のバージョンと異なります。
    - タイトルバーを表示しなくなりました。
    - これらの画面を個別にフォーカスしたり操作したりできなくなりました。
    - これらの画面を個別に閉じられなくなりました。
    - これらの画面を閉じても、付着先の画面が一緒に閉じられなくなりました。
    - 付着する画面は付着先の画面の拡大率を引き継ぎます。
- 一部のネイティブ風画面で、既定のアンカーポイントが指定されていないためにノードの位置が揺れる問題を修正しました。
- モジュールカード内の「プレビュー画像」の描画を全面的に作り直し、複数のプレビュー画像がある場合は完全なカルーセルコンポーネントとして描画し、素早い切り替えに対応しました。
- コンテンツ内でも上りパケットの優先度が上がってしまう問題を修正しました。
