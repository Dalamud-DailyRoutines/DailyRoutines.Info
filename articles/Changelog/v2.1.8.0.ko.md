## 본체 변경

- 중국 본토 이외의 네트워크 환경에서 Universalis 서비스에 접속하는 경험을 대폭 개선했습니다.
- 만진법 숫자 표기 기능이 한국어를 지원합니다.
- 공유 이동 로직이 일부 지역에서 존재하지 않는 지역 전환 라인을 사용하려던 문제를 수정했습니다.

## 새로운 모듈

### * 도시 내 에테라이트 지도 텔레포 [인터페이스]

*추천 모듈*

지도에서 도시 내 에테라이트를 직접 클릭하여 에테라이트처럼 텔레포를 실행할 수 있습니다.

### * 게임 설정 자동 백업 [시스템]

설정 후 게임 로그인 시 게임 설정 데이터를 GitHub Gist에 자동으로 동기화하며, 충돌 자동 감지와 클라우드 복원을 지원합니다.

## 모듈 변경

### 모그루 모그 우편함 UI 최적화 [인터페이스]

- 버튼 텍스트가 중복 표시되던 문제를 수정했습니다.
- 「편지 수령」「편지 삭제」기능의 로직을 완전히 재구성하여 더 하위 레벨의 호출 방식을 사용함으로써 조작 속도가 크게 향상되었습니다.
- 오작동을 방지하기 위해 「모든 첨부 아이템 일괄 수령」 버튼을 길게 눌러야 발동되도록 변경했습니다.
- 모듈이 변경한 「상품/구매품 배달 요청」 버튼을 클릭하면 클릭 효과를 알리는 알림 메시지가 전송됩니다.

### 【청마도사】 자동 에테르 복사 [액션]

- 창 내 일부 영역을 클릭할 수 없던 문제를 수정했습니다.
- 창의 용도를 더 명확히 알 수 있도록 창 제목을 추가했습니다.
- 창 버튼의 외형을 개선하고 버튼을 키우며, 청마도사 아이콘을 명확하게 표시하도록 했습니다.
- 알림 메시지의 외형 스타일을 조정했습니다.

### 빠른 서버 텔레포트 명령어 [시스템]

- 알림 메시지의 외형 스타일을 조정했습니다.
- 「서버 정보 바에 빠른 서버 텔레포 진입 메뉴를 추가합니다」설정을 켜면 게임의 「현재 서버 이름 표시」설정이 자동으로 비활성화됩니다.

### 네트워크 지연 자동 표시 [인터페이스]

- 창의 지표 라벨에 지역화 텍스트를 추가했습니다.
- 창의 각 지표 수치의 글자 크기를 키웠습니다.
- 간결함을 위해 서버 정보 바 항목의 기본 포맷 텍스트에서 「지연: 」부분을 제거했습니다. 현재는 「90ms」와 같은 텍스트로 표시됩니다.

### 버프 중복 방지 [액션]

- 서포터 역할의 마법사 계열 기술 「마기 시전방해」를 제거했습니다.

### 어디서든 장터 게시판 [인터페이스]

- 창의 외형 스타일과 상호작용 로직 설계를 대폭 재구성했습니다.

![BetterMarketBoard-UI](/assets/Changelog/2.1.8.0/BetterMarketBoard-UI.png)

- 현재 서버의 장터 데이터를 검색할 수 있는 시점을 더욱 제한하여 의도하지 않은 데이터 패킷 전송을 방지했습니다.
- 선택한 서버가 현재 서버와 다른 지역에 있을 때 「장터 데이터 새로고침」 버튼을 클릭하면 서버 선택 구성 요소가 영구히 사라지던 문제를 수정했습니다.
- 지역을 전환할 때 장터 데이터와 선택한 아이템 정보가 자동으로 초기화되던 방식을 제거했습니다.
- 서버를 전환할 때 데이터가 즉시 갱신되지 않던 문제를 수정했습니다.
- 가격 모니터링 기능을 설정 창에서 창 내부로 완전히 옮겼습니다.
- 고품질(HQ) 여부를 구분하는 설정 항목을 자동 구매 하위 기능에서 가격 모니터링 기능으로 이동했습니다.
- 「자동 구매」기능의 테스트 코드 요구 사항을 제거했습니다.
- 알림 메시지의 외형 스타일을 조정했습니다.
- 「장터 게시판 검색 결과 자동 새로고침」 모듈을 선행 모듈에서 추천 모듈로 변경했습니다.
- `/pdr market` 명령어 도움말 텍스트에 인수를 전달할 수 있다는 내용이 없던 문제를 수정했습니다.
- 일부 상황에서 자신의 집사가 판매한 아이템을 구매할 수 있던 문제를 차단했습니다.

### 장터 게시판 검색 결과 자동 새로고침 [인터페이스]

- IPC `DailyRoutines.Modules.AutoRefreshMarketSearchResult.IsMarketStuck`을 제거했습니다.
- 로직을 대폭 간소화했습니다.

### 집사 수행 자동화 [인터페이스]

- 선행 모듈 「어디서든 장터 게시판」을 추가했습니다.
    - 장터 데이터 요청과 표시 로직은 모두 이 선행 모듈이 담당하므로, 해당 모듈을 활성화하지 않으면 「집사 자동 가격 변경」기능을 정상적으로 사용할 수 없습니다.

### 매크로 대상 파라미터 확장 [시스템]

- 적대 대상 여부를 판별하는 로직을 조정했습니다.

### 【청마도사】 청마법 활성 세트 불러오기 개선 [시스템]

- 카테고리를 「인터페이스」에서 「시스템」으로 변경했습니다.
- 로직을 완전히 재구성하여 더 하위 레벨의 구현 방식을 채택함으로써 더 많은 시나리오를 지원합니다.
- 알림 메시지의 외형 스타일을 조정했습니다.
- 언로드 시 명령 등록이 정리되지 않던 문제를 수정했습니다.

### 보물지도 위치 자동 표시 [시스템]

- 보물지도 위치를 표시할 때 지도 화면 상단에 해당 보물지도의 이름도 함께 표시합니다.
