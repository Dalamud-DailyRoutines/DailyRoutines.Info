## 본체 변경 사항

- 모듈 카드에 ‘오늘의 추천’ 태그를 추가하여 ‘추천 모듈’을 표시합니다.
- 인터페이스 폰트 크기를 변경하는 과정에서 폰트 재구성이 빈번하게 발생하던 문제를 수정했습니다.
- 기록된 이전 버전을 유효한 버전으로 분석할 수 없을 때 메인 인터페이스를 열 수 없던 문제를 수정했습니다.
- 버전 업데이트 인터페이스의 외형 스타일을 전면적으로 재구성했습니다. 업데이트 기록 표시를 추가했습니다.
- 최초 사용 설정 인터페이스를 추가했습니다. 여기에서 중요 설정을 구성하고 플러그인을 파악할 수 있습니다. 최초 설정을 완료하지 않으면 어떤 모듈도 로드되지 않습니다.
- 혼동을 피하기 위해 모듈 정보 내 ‘추천 모듈’을 ‘연동 모듈’로 이름을 변경했습니다.
- 설정 인터페이스의 외형 스타일을 재구성하여 단일 열 레이아웃으로 변경하고 텍스트를 더 완전하게 표시하도록 했습니다.
- 설정 항목 ‘점프 상태 수정’을 제거했습니다.

## 신규 모듈

### 잘못된 마수 편성 자동 차단 [콘텐츠]

*추천 모듈*

‘마수 시련장’에서 현재 편성된 마수가 3마리 미만일 경우 도전을 시작할 수 없으며, 마수가 설정되지 않은 호루라기가 있을 경우 전투를 시작할 수 없도록 하여 사전 방지합니다.

### 석공의 이론·농부의 지혜 자동 사용 금지 [제작 및 채집]

*추천 모듈*

‘샘솟는 지혜 시전 가능’ 상태에서는 ‘석공의 이론’과 ‘농부의 지혜’ 사용을 금지하여 GP 낭비를 방지합니다.

### ‘/대인기술시전’ 명령어 개선 [액션]

*추천 모듈*

“/대인기술시전(/pvpaction, /pvpac)” 명령어에서 콤보 기술 등 단축바에 등록할 수 없는 기술의 이름도 입력할 수 있도록 합니다.
(예: /대인기술시전 글레어쟈, /대인기술시전 폭도의 검격)

### ‘PvP 전용 직업 스킬’ 화면 개선 [인터페이스]

*추천 모듈*

‘PvP 전용 직업 기술’ 화면을 개선하여, 기존에는 단축바에 등록할 수 없던 스킬도 드래그하여 PvP 전용 단축바에 등록할 수 있도록 합니다.

## 모듈 변경 사항

### 디아뎀 제도 자동 채집 [스크립트]

- 게임 데이터가 제때 갱신되지 않아 잘못된 종점으로 경로 탐색하던 문제를 수정했습니다.

### 【청마도사】 청마법 활성 세트 불러오기 개선 [시스템]

- 활성 세트를 불러올 때 해당 단축바가 자동으로 로드되지 않던 문제를 수정했습니다.

### 바로가기 패널 인터페이스 최적화 [인터페이스]

- 모듈 로직을 전면적으로 재구성하여, 이제 각종 조작 로직과 동작이 단축바와 완전히 일치합니다. 구체적으로 잠금 상태에서는:
    - 인터페이스를 드래그할 수 없으며, 마우스 커서가 손 모양 드래그 아이콘으로 바뀌지 않습니다.
    - Esc 키로 인터페이스를 닫을 수 없으며, 키 입력은 정상적으로 다른 게임 로직으로 전달됩니다.
    - 각 슬롯을 드래그하여 교체할 수 없습니다.
    - 슬롯 우클릭 메뉴를 열 수 없습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 잠금 버튼의 위치를 조정했습니다.
- 잠금 버튼의 호버 텍스트 안내를 제거하여 단축바와 일치시켰습니다.

### 줌 거리 설정 [시스템]

- 콘텐츠 ‘마수 시련장’의 전투 구역에 진입한 뒤 설정이 적용되지 않던 문제를 수정했습니다.

### 잠수함 재료 자동 회수 [인터페이스]

- 로그인 후 탐사 상황 알림 메시지가 제때 전송되지 않던 문제를 수정했습니다.

### 자동 마테리아 장착 [인터페이스]

- 웹사이트 최신 버전의 내보내기 데이터에 대응했습니다.
- 모듈 인터페이스의 외형 스타일과 조작 로직을 전면적으로 재구성했습니다.

![AutoMateriaAttach-UI](/assets/Changelog/2.2.0.0/AutoMateriaAttach-UI.png)

### 터보 클릭 [시스템]

- 게임패드 모드에서 게임패드로 인터페이스를 스크롤할 수 없던 문제를 수정했습니다.
- 설정 항목 ‘트리거 키’를 제거했습니다.
- 설정 인터페이스의 외형을 조정했습니다.

### 빠른 탈것 탑승 [시스템]

- 함께 탑승할 수 있는 팀원을 우클릭할 때, 우클릭 메뉴를 연 뒤 닫는 방식에서 우클릭 메뉴가 열리는 것 자체를 차단하는 방식으로 변경했습니다.
- 첫 번째 위치를 고정으로 전달하여 서버가 빈자리를 자동 배정하도록 하는 방식에서, 로컬에서 빈자리를 직접 가져와 전달하는 방식으로 변경했습니다.
- 이제 일부 함께 탑승 조건을 충족하지 않아도 우클릭 메뉴가 열리는 것을 차단하지 않습니다.
- 알림 메시지를 추가했습니다.
- 모듈 설명 텍스트를 조정했습니다.
- 명령어 ‘/pdr ridepillion’를 추가했습니다. 사용하면 주변 팀원의 탈것에 자동으로 함께 탑승합니다.

### 퀘스트 전투 매우 쉬움 설정 [전투]

- 알림 메시지가 중복 전송되던 문제를 수정했습니다.
- 알림 메시지의 내용과 외형 스타일을 조정했습니다.
- 모듈 설명 텍스트를 조정했습니다.

### 저레벨 스킬 자동 대체 [액션]

- 스킬 대체를 추가했습니다:
    - 블리자쟈 → 블리자드
    - 파이쟈 → 파이어

### 사용자 지정 지도 표식 [인터페이스]

- 시야를 가리지 않도록 지도 인터페이스의 버튼을 오른쪽 위에서 오른쪽 아래로 이동했습니다.

### FPS 제한 설정 개선 [시스템]

- ‘FPS 제한’ 인터페이스의 높이가 흔들리던 문제를 수정했습니다.
- ‘FPS 제한’ 인터페이스에서 현재 FPS 표시 텍스트의 위치를 조정하여 겹침을 방지했습니다.
- FPS 제한 메커니즘을 전면적으로 재구성하여 제한과 측정이 더 정확하고 안정적으로 동작하도록 했습니다.

### 집사 수행 자동화 [인터페이스]

- 일괄 가격 변경이 완료되면 장터 게시판 인터페이스를 자동으로 닫습니다.
- 인터페이스가 게임패드 조작을 지원합니다.

### 희귀품 조달 자동화 [인터페이스]

- 인터페이스가 게임패드 조작을 지원합니다.

### 개선된 서포트 직업 목록 [인터페이스]

- 인터페이스가 게임패드 조작을 지원합니다.
- 애니메이션 구현 방식을 조정하여 기본 인터페이스와 일치시켰습니다.

### 군표 교환소 아이템 교환 간소화 [인터페이스]

- 구현 로직을 전면적으로 재구성하여 교환 속도를 크게 향상시켰습니다.
