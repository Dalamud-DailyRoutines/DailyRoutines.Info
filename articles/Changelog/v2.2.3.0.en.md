## General Changes

- Optimized how the Wine environment is detected.
- Updated the verification component related to "TID".
- Removed the mechanism that forced online verification connections to bypass the system proxy.
- Raised the priority of initialization loading.
- Fixed an issue where overly long images in the changelog window overflowed the visible area.
- Added the "No Proxy For Authentication" option under "General". Online verification requests ignore the system proxy settings and connect to the verification server directly. This option has no effect when a global transparent proxy such as a virtual network adapter is in use. Disabled by default, which matches the behavior of previous versions.
- Added the "Tray Notification Delay When Active" option under "General". When the idle time reaches the configured value, a Windows tray notification appears even if the game is in the foreground. Setting it to 0 means notifications are only shown when the game is in the background. The default is 15000 milliseconds, which matches the behavior of previous versions.
- Context menu handling now supports the "Item Search" window.
- Adjusted the help text of the "Interrupt Hotkey" option under "General".
- The "Interrupt Hotkey" display now shows the keyboard or gamepad binding according to the current control mode.
- Fixed an issue where the debug window did not clear cached modules in time, which left old module instances unreleased after "Reload Modules".
- Fixed an issue where the JSON converter was not cleared in time, which prevented assemblies from being collected.
- Fixed an issue where Newtonsoft.Json generated dynamic method references for key-value pair serialization, which prevented assemblies from being collected.
- "Reload Modules" now triggers a full garbage collection every time.
- Fully reimplemented every window attached around native windows. They now rely entirely on the game's native child window system. Because the implementation differs, their appearance and interaction also differ from previous versions.
    - Title bars are no longer displayed.
    - These windows can no longer be focused or operated individually.
    - These windows can no longer be closed individually.
    - Closing these windows no longer closes the window they are attached to.
    - Attached windows inherit the scale of the window they are attached to.
- Fixed an issue where nodes in some native-style windows jittered because no default anchor point was specified.
- Fully reimplemented how preview images in module cards are drawn. When several preview images exist, they now render as a complete carousel component that supports quick switching.
- Fixed an issue where the priority of outgoing packets was still raised inside duties.
