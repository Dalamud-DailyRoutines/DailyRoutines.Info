## 本体修改

- 优化了 Wine 环境的检测方式。
- 更新了“设备认证凭证”相关的验证获取组件。
- 移除了在线验证连接强制不走系统代理的机制。
- 提高了初始化加载的优先级。
- 修复了更新日志界面中过长的图片会溢出可视区域的问题。
- 新增“一般”下配置项“在线验证绕过系统代理”。发送在线验证请求时忽略系统代理设置，直接连接验证服务器。若使用虚拟网卡等全局透明代理方式，本选项无效。默认禁用，与先前版本行为一致。
- 新增“一般”下配置项“前台无操作通知提醒时间（毫秒）”。当持续无操作的时间达到设定值时，即使游戏位于前台，也会展示 Windows 托盘通知。设为 0 时表示永远仅游戏位于后台时才通知。默认 15000 毫秒，与先前版本行为一致。
- 右键菜单解析现在支持“道具搜索”界面。
- 调整了“一般”下配置项“打断热键”的帮助文本，
- 显示“打断热键”时将根据当前游戏操作模式分别显示键盘按键或手柄按键的设置值。
- 修复了因调试视图未及时清理缓存模块导致“重载模块”功能会致使无法回收旧有模块实例的问题。
- 修复了因 JSON 转换器未及时清理导致无法回收程序集的问题。
- 修复了因 Newtonsoft.Json 会为键值对序列化生成动态方法引用导致无法回收程序集的问题。
- 现在每次“重载模块”时，都会触发一次完整垃圾回收。
- 完全重构了所有附着在原生界面周围的界面的实现方式。现在完全使用游戏原生的子界面系统实现。因实现方式不同，外观与交互方式也会与先前版本不同。
    - 不再显示标题栏。
    - 无法再单独焦点或操控这些界面。
    - 无法再单独关闭这些界面。
    - 关闭这些界面不再会一并关闭被附着的界面。
    - 附着界面会继承被附着界面的缩放。
- 修复了部分原生风格界面的节点的位置因未指定默认锚点而产生抖动的问题。
- 完全重构了模块卡片组件内“预览图”的绘制，现在存在多张预览图时会渲染为完整的轮播组件，并支持快速切换。
- 修复了在副本内仍会提高上行数据包优先级的问题。
