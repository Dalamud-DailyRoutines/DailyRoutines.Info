## 본체 변경

- 인증 화면 내 일부 잘못된 현지화 텍스트를 수정했습니다.
- 번체자 서비스 지역에서 실제로 오픈되지 않은 테스트 서버를 제외했습니다.

## 신규 모듈

### '아씨엔 나브리알레스 토벌전' 도우미 [콘텐츠]

*추천 모듈*

'아씨엔 나브리알레스 토벌전'에 입장 시, 자신의 현재 상태에 맞춰 부딪혀야 할 구체를 자동으로 강조 표시합니다.

### 타겟 선택 상태 자동 유지 [시스템]

*온라인 인증*

타겟이 유효 범위를 벗어나도 대상 선택이 자동으로 해제되지 않습니다. 메모리에 남아 있는 한 타겟 선택 상태를 유지할 수 있습니다. 또한, 주시 대상 UI에서 사거리 밖의 대상을 다시 선택할 수도 있습니다.

## 모듈 변경

### 자동 돌발 임무 [스크립트]

- '정기 휴식' 설정 항목을 추가했습니다. 모듈이 일정 시간 동작한 후 도시 지역으로 이동하여 일정 시간 동안 휴식함으로써 실제 플레이어의 생활 패턴을 모방합니다. (기본값: 비활성화)
- 에테라이트 선택 로직에서, 일반적인 방법으로는 텔레포트로 직접 이동할 수 없는 도시 내 에테라이트를 모두 제외했습니다.
- 비행(플라잉) 상태에서 이미 진행 중인 수집형 돌발 임무 범위에 진입했을 때 탈것에서 제대로 내리지 못하던 문제를 수정했습니다.
- 해당 버디 기술(스탠스)을 습득한 경우에만 버디의 스탠스 전환을 시도하도록 변경했습니다.

### '초승달 섬' 도우미 [콘텐츠]

- '포크 타워: 마의 탑'이 재등장(리젠)할 때 남은 시간이 표시되던 문제를 수정했습니다.
- 길찾기 기능의 탈것 탑승 로직을, 길찾기 시작 시 1회만 판정하던 방식에서 이동 중 경로 길이에 따라 탑승 여부를 결정하는 방식으로 변경했습니다.
- 마도 통로에 정확히 접근하지 못하던 문제를 수정했습니다.
- 탈것 탑승 거리 임계값을 50에서 40으로 낮췄습니다.
- 돌발 임무로 길찾기 시, 대상에 충분히 접근한 후에 돌발 임무 몬스터를 선택(타겟팅)하도록 변경했습니다.

### '거두지 않는 섬' 도우미 [콘텐츠]

- 온라인 인증 요구 조건을 제거했습니다.

### '돌발임무 달성도' UI 개선 [인터페이스]

- 모듈 구현 로직을 간소화했습니다.
- 로그인 상태일 때만 진행도 데이터를 요청하도록 변경했습니다.

### 전투 효과 자동 조정 [전투]

- '인스턴스 던전 내' 탭에서 콘텐츠 카테고리를 활성화하면, 구분을 돕고 한눈에 알아볼 수 있도록 해당 제목 문구가 초록색으로 변경됩니다.
- '인스턴스 던전 내' 탭에서 각 콘텐츠 카테고리의 ID 표시를 제거했습니다.

### 빠른 서버 텔레포트 명령어 [시스템]

- 구현 로직을 최적화하고 간소화했습니다.
- 모든 알림에 게임 기본(네이티브) 알림 시스템을 사용하도록 변경했습니다.
- 전송되는 각종 알림 메시지의 내용을 더욱 상세하게 보강했습니다.
- 서버 간 텔레포트가 허용되지 않는 지역에서 요청 시, 텔레포트 가능 지역으로 복귀하는 처리를 플러그인 내부의 통합 지역 이동 로직이 담당하도록 변경했습니다.
- 서버 정보 표시줄 항목을 우클릭하여 홈 월드로 돌아가는 기능에, 오클릭을 방지하기 위한 재확인 창을 추가했습니다.
    - '홈 월드로 돌아가기 확인 건너뛰기' 설정 항목을 추가했습니다. 해당 설정을 직접 활성화하면 새로 추가된 재확인 창을 건너뛸 수 있습니다.

### 탈것 금지/풍맥 제한 해제 [시스템]

- 정상 작동하지 않던 기능을 수정하고, 최신 버전의 메모리 구조에 대응했습니다.

### 버디(초코보) 자동 소환 [전투]

- '알림 메시지 전송' 및 '음성 메시지 전송' 설정 항목을 제거했습니다.
- 알림 메시지의 표시 스타일을 조정했습니다.
- '버디' 기능(버디 동행)을 해금한 경우에만 버디(초코보) 소환을 시도하도록 변경했습니다.

### 추억의 보관함 자동 보관 [인터페이스]

- 장비함에 보관된 장비를 대상에서 제외했습니다.
