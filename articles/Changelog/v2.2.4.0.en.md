## Core Changes

- Fixed the issue where the label text color of dropdown components displayed incorrectly under color themes other than "Transparent White".
- Modules that do not apply to the current client are no longer loaded.
- When not verified, modules that require verification are no longer displayed.

## New Modules

### Duty Leaving Command [Assistance]

*Recommended Module*

Added the "/pdr leaveduty" command to leave a duty quickly.

### Theme Loading On The Fly [Addon]

*Recommended Module*

Makes color theme settings take effect immediately without logging out of the game.

(Because this module is rather special, other features that use native addons and nodes have also been refactored on a large scale to support loading color themes on the fly.)

## Removed Modules

Due to malicious publicity, in addition to the modules listed below, about 20 modules originally intended for internal testing only have been completely removed from the plugin.

### Safe Object Carrying [General]

Its actual effect was mediocre and too many edge cases needed to be handled, so it has been removed.

### Jump To Duties In Wondrous Tails [Addon]

Its data needed maintenance on every version update, which took too much effort, and no one maintains it now, so it has been removed.

## Module Changes

### Auto Open Treasure Coffer [Duty]

- Without the tester qualification, the feature now takes effect only in solo play.

### Fast Teleportation Panel [Addon]

- Without the tester qualification, the feature now takes effect only in areas without movement speed checks.

### Better Crafting Log [Addon]

- Adjusted the name and description.
- Adjusted the appearance and content of notifications.
- During batch crafting, if the Crafting Log is not currently open, it will be reopened.
- During batch crafting, usable materials will be selected automatically.
- Inside the "Solution Steps" window, the default number of crafts is now calculated dynamically based on the materials you hold.
- The "Solution Steps" window now shows the progress and quality that the solution is expected to reach.
- The separate "Copy Macro" row inside the "Solution Steps" window has been removed. As a replacement, a button has been added at the upper right of the action preview container; clicking it opens a menu where a macro can be selected and copied.

![OptimizedRecipeNote-Addon](/assets/Changelog/2.2.4.0/OptimizedRecipeNote.png)

- Added two preview images.

### Better BLU Active Set [System]

- Adjusted the description.
- Fixed an issue where, when any active set was unnamed, loading via command could load the wrong active set.
- Loading unnamed active sets via command is now supported.

### Better Blacklist [System]

- Fixed an issue where some menu items in the context menu incorrectly showed a submenu marker.
- Fixed an issue where shared blacklists with more than 1000 entries could not be retrieved completely.

### Better World Visit [System]

- Adjusted the description.
- The size is now always calculated dynamically based on the interface elements.
- Each server component in the window can now retrieve and display, in real time, the server travel status available to the client.
- Optimized the lifecycle management logic of the window.
- (International servers only) Supports direct world travel within Japanese physical data centers.
