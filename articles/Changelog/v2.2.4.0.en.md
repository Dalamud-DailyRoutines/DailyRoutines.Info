## Plugin Changes

- Fixed an issue where the dropdown component label text color displayed abnormally under color themes other than "Clear White".
- Modules that do not apply to the current client are no longer loaded.
- Modules that require verification are no longer displayed when not verified.

## New Modules

### Leave Duty Command [Assistance]

*Recommended Module*

Adds the "/pdr leaveduty" command to quickly leave a duty.

## Removed Modules

Due to malicious promotion, approximately 20 Tester modules besides the ones listed below have been removed from the plugin.

### Safe Object Carrying [General]

The effect was mediocre in practice and too many edge cases had to be handled, so it has been removed.

### Jump To Duties In Wondrous Tails [Addon]

Every game update required maintaining the data, which took too much effort, and nobody maintains it now, so it has been removed.
