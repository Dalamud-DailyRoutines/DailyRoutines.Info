## Plugin Changes

- Fixed an issue where dropdown component label text was shown in the wrong color under color themes other than "Clear White".
- Modules that do not apply to the current client are no longer loaded.
- Modules that require verification are no longer displayed while unverified.
- Fixed a crash under Wine that occurred when a notification was sent while any module that sends notifications was enabled.
- Fixed an issue where a failure to parse localized strings threw the exception outwards.

## New Modules

### Duty Leaving Command [Assistance]

*Recommended module*

Added the "/pdr leaveduty" command for leaving a duty quickly.

### Theme Loading On The Fly [Addon]

*Recommended module*

Color theme settings now take effect immediately, without logging out of the game.

(As this module is rather unusual, other features that use native addons and nodes were also extensively refactored along with it to support theme hot reload.)

### Movement Lock While Casting [Action]

Movement is blocked automatically while casting an action, so that the cast is not interrupted by accident.

## Removed Modules

Because of the potential for abuse, about 20 modules that had been intended only for internal testing have been removed from the plugin entirely, in addition to the modules listed below.

### Safe Object Carrying [General]

Its effect was unremarkable, and it required handling too many edge cases, so it was removed.

### Jump To Duties In Wondrous Tails [Addon]

The data had to be maintained with every version update, which cost far too much effort, and nobody maintains it at present, so it was removed.

## Module Changes

### Auto Open Treasure Coffer [Duty]

- Without an internal test credential, the feature now works only while solo.

### Fast Teleportation Panel [Addon]

- Without an internal test credential, the feature now works only in areas where movement speed is not detected.

### Better Crafting Log [Addon]

- Adjusted the name and description.
- Adjusted the appearance and content of notifications.
- During batch synthesis, the Crafting Log is opened once more if it is not currently open.
- During batch synthesis, available materials are selected automatically.
- In the "Solution Steps" window, the default number of syntheses is now calculated dynamically from the materials you hold.
- In the "Solution Steps" window, the progress and quality the solution is expected to reach are now displayed.
- The separate "Copy Macro" row in the "Solution Steps" window has been removed. In its place, a button has been added at the upper right of the action preview container; clicking it opens a menu where a macro can be selected and copied.

![OptimizedRecipeNote-Addon](/assets/Changelog/2.2.4.0/OptimizedRecipeNote.webp)

- Two preview images have been added.

### Better BLU Active Set [System]

- Adjusted the description.
- Fixed an issue where loading from a command could load the wrong active set when any valid set was unnamed.
- Unnamed valid sets can now be loaded from a command.

### Better Blacklist [System]

- Fixed an issue where some right-click menu entries incorrectly showed a submenu marker.
- Fixed an issue where shared blacklists with more than 1000 entries could not be retrieved in full.
- Added an attached window next to the "Blacklist" window for quick operations on the game's native blacklist.
    - Function button "Remove Invalid Entries". Remove invalid entries based on the stale account ID format between Patch "Crossroads" and Patch "The Promise of Tomorrow".
    - Function button "Remove Legacy Entries". Remove legacy entries based on the stale character ID format before Patch "Crossroads".
    - Function button "Better Blacklist". Opens the configuration window.
    - Function button "Remove All Entries". Removes all recorded entries.
- Removed the "Better Blacklist" button from the upper left of the "Blacklist" window.
- The right-click menu entry for adding a player to the native blacklist is no longer blocked.
- Fixed an issue where, with only a local blacklist and no shared one, its data took effect only after the first zone change or blacklist edit.
- Adding a player to a blacklist or removing one now updates that player's name text, character visibility, and other information immediately.
- Fixed an issue where notifications could still show outdated information after local blacklist information was edited.
- When a player is on multiple blacklists, notifications now show the information from every blacklist in full.
- Joining a shared blacklist now reports a failure, rather than creating an empty group, when the target blacklist does not exist.
- Added failure messages for some shared blacklist operations.
- Fixed an issue where you could enter your own character information when manually adding a blacklisted player from the window.

### Better World Visit [System]

- Adjusted the description.
- Its size is now always calculated dynamically from UI elements.
- Each server component in the window now retrieves and displays the server travel status available to the client in real time.
- Improved the lifecycle management logic of the window.
- (Global version only) Direct world visits within Japanese physical data centers are now supported.

### Auto Chat Bot Reply [System]

- Adjusted the description.
- Fixed an issue where starting an auto reply called the filter model one extra time.
- Fixed an issue where multiple tool calls within a single response could not be handled.
- Fixed an issue where the tool results of the current round were sometimes not filled in for streaming replies.
- Fixed an issue where Ollama tool parameters were parsed incorrectly.
- Fixed an issue where streaming chunks generated by Ollama were sometimes ordered incorrectly.
- Fixed an issue where an empty placeholder message could be sent in the test chat.
- Added the "Send Temperature" and "Enable Max Completion Tokens" configuration options.

### Auto Dismount [Action]

- Adjusted the description.
- Improved how actions that currently cannot be used are determined.
- Improved performance.

### Better Frame Rate Cap [System]

- Adjusted the description.
- Extended the parameters available for the "/pdr fps" command.
    - No argument: opens or closes the "frame rate cap" window.
    - `on`: caps the frame rate.
    - `off`: does not cap the frame rate.
    - `toggle`: caps or uncaps the frame rate.
    - `<frame rate>`: sets the target frame rate (an integer from 1 to 32767) and caps the frame rate.
- Running the "/pdr fps" command now sends a notification.
- The frame rate metrics in the overlay are now displayed as localized text.
- The configured frame rate cap is no longer displayed in the overlay, because it is not actually a metric.

### Auto Game Config Backup [System]

- Fixed an issue where the first manual backup could create a Gist more than once.
- Fixed an issue where a failed restore from the cloud could leave an incomplete configuration behind.
- Improved how backup files are generated, so that the backup manifest and the backup file no longer differ in the rare case where the game saves the configuration between generating them.
- Fixed an issue where editing the configuration during a backup wrote incorrect data.
- Improved performance.

### Selectable Recruitment Texts [Addon]

- The implementation was completely reworked and now relies on a lower-level, more robust approach.
- Fixed an issue where auto-translation phrases could not be displayed.

### Actual Position In Queue [System]

- Adjusted the name and description.
- Greatly simplified the module implementation.

### Auto Spam Key [System]

- Adjusted the description.
- Fixed an issue where the "Duty Actions" window could not be operated with a gamepad.

### Better Market Board [Addon]

- Fixed an issue where the left sidebar was too narrow when the window was first opened.

### Auto Collect Subaquatic Voyages [Addon]

- Adjusted the module description.
- Adjusted the text shown in notifications and in the window.
- Adjusted the appearance of submersible-related items (Magitek Repair Materials and Ceruleum Tank) in the "voyage control panel" window.
    - They now match the native item display and can be right-clicked to open a menu.
    - Fixed an issue where the icon, item name, and quantity were not aligned vertically.
- Adjusted the appearance of the "Auto Collect Subaquatic Voyages" button in the "voyage control panel" window.
