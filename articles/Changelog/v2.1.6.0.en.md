## Framework Changes

- The performance of some background tasks has been improved.
- An issue that, navigation process may get stuck in the non-instanced areas which could be reached via a settlement aethernet, has been fixed.
- An issue of unexpected 1-second delay before interacting with an aetheryte has been fixed.
- An issue that the character may interact with an unexpected aethernet shard has been fixed.
- Now it will consider routes with transfers less often when the option "Minimal Gil Navigation" is disabled for better efficiency.
- Requests to Universalis have been improved.

## New Modules

### Burn Helper [Duty]

*Recommended Module*

Automatically prevent targeting and attacking "Mist Dragon" when it's holding the status "Vaporize" in the duty "Burn".

## Module Changes

### Occult Crescent Helper [Duty]

- The drawing logic of the configuration interface has been fully refactored.
    - A better tab nesting has been introduced in order to replace the fragmentary inaccessible design before.
    - Now the Return-To-Origin button is available with a button text in the "Coffer" tab.
    - The map provided by the "Auto Collect Coffers" feature has been improved.
        - Now the map is pinned to the top-left corner of the screen.
        - The nodes and paths have been bolded.
        - Now the character is marked as a triangle, which could better indicate the orientation.
    - Now a map with a detailed path will be displayed while hovering over a coffer collection button. The path is calculated in real time based on the character's position.
- The performance when the module is not enabled has been improved.
- The "Auto Collect Coffers" feature has been fully refactored.
    - Now the character will move at a certain altitude underground, which means the altitude would no longer vary based on the surface altitude.
    - Now the character will dismount before casting Occult Return after completing a route.
    - The routes have been redesigned.
        - North Horn: 30 locations in the inner loop, 38 locations in the outer loop
        - South Horn: 23 locations in the inner loop, 45 locations in the outer loop
- The "Auto Enable / Disable Plugin" feature has been removed. The feature has been inherited by two new features "Commands While Joining" and "Commands While Leaving" for better customization.
    - Related checkboxes have also been removed. Leave the input boxes blank to disable the new features.
- An issue that the command `/pdr ptp` didn't work in North Horn has been fixed.
- An issue of unexpected exception throwing when the index parameter of the command `/pdr ptp` is illegal has been fixed.
- Now the module will call vnavmesh to determine the occult aetheryte closest to the target dynamic event.
- Now the character prefers running over mounting while approaching a nearby occult aetheryte.

### Auto FATE [Script]

- The "Item" mode has been fully refactored and renamed to "custom".
    - The appearance and interaction have been refactored adopting a better layout.
    - Now users could set minimum FATE runs for each zone.
    - Now users could set minions to be summoned for each zone.
    - Now users could set macros to be executed for each zone.
    - Now users could create a custom preset based on a pre-made preset.
- New pre-made presets have been introduced.
    - Phantom Weapon Obscurum
    - Phantom Weapon Occultum
    - Yo-kai Medal
    - Yo-kai Legendary Medal
- Now the character will dismount after approaching a FATE enemy within the FATE range and when the nearby ground is dismountable.

### Portrait Emote Frame By Frame [Interface]

- The module has been fully refactored. The implementation has been streamlined. The interface is now in vanilla game assets.
    - Now the module works based on per emote frame. The buttons "Rounding", "+10" and "-10" have been removed, and the buttons "+1" and "-1" will jump to an integer frame first after clicking.

### Auto Discard Items [System]

- New option "Add To Group" in the right-click menu, to add an item to the specified group.

### Nearby Player Counter & Radar [General]

- Now the acquisition interval of players in the current zone has been increased from 10 seconds up to 60 seconds.
- Now the module will attempt to acquire player data immediately after switching zones.

### Auto Commend Party Member [Duty]

- Now a chat message will be sent after designating a party member via the right-click menu instead of a notification in the past.
- Now the option "No Commendation" is provided in the right-click menu of the character self.
- Notification texts have been adjusted.
