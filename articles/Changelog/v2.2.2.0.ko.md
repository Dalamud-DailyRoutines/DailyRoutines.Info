## 본체 수정

- 중국 서버에만 적용되는 일부 로직이 글로벌 서버 환경에서도 정리 처리를 시도하여 null 참조 예외가 발생하던 문제를 수정했습니다.
- 모든 자체 제작 네이티브 인터페이스의 제목이 글로벌 서버 환경에서 표시되지 않던 문제를 수정했습니다.
- 이제 메인 화면 왼쪽 사이드바 창의 버전 번호 텍스트를 클릭하여 업데이트 기록 창을 다시 열 수 있습니다.
- 업데이트 기록이 창 안에서 Markdown으로 올바르게 렌더링됩니다.
- 우클릭 메뉴 분석이 "출품 목록" 창을 지원합니다.
- 출력되는 오류 메시지의 외형이 네이티브 오류 메시지의 외형과 일치하지 않던 문제를 수정했습니다.
- "아이템 상세 정보" 및 "기술 상세 정보" 창 관련 수정의 표시 효과를 개선했습니다.
- IPv6 네트워크 환경에서 온라인 인증 서비스에 연결하기 어려운 문제를 개선했습니다.

### 알림 기능 일괄 조정에 관한 안내

(다음 변경 사항은 여러 버전에 걸쳐 조정이 완료될 수 있습니다.)

- "텍스트 음성 변환" 기능이 별도의 `EdgeTTS.Dalamud` 플러그인으로 분리되었고, 해당 기능이 동작상 침투감이 강하기 때문에, 이제는 "Windows 트레이 알림"을 보내고 해당 플러그인이 활성화된 것을 감지한 경우에만 트레이 알림의 메시지 내용을 함께 읽습니다.
- "채팅 메시지" 계열 알림은 두 가지로 구분됩니다.
    - "DR" 접두사 있음: 내용이 명확히 플러그인에서 제공하는 기능으로만 발생할 수 있는 알림 메시지.
      예시: 내용이 "일괄 제작 완료"인 알림 메시지, 내용이 "장터의 특정 아이템 가격이 설정값보다 낮음"인 알림 메시지, 내용이 "잠수함이 모두 귀환함"이지만 메시지와 상호작용하여 자동으로 회수하러 갈 수 있는 알림 메시지.
    - "DR" 접두사 없음: 내용이 게임 자체에서도 발생할 수 있으며, 단지 표시되지 않았거나 명확히 알림되지 않았던 알림 메시지.
      예시: 내용이 "이동 속도 감지 구역에 진입함"인 알림 메시지, 내용이 "게임에 정상적으로 로그인함"인 알림 메시지, 내용이 "밀려나기 효과를 받음"인 알림 메시지.
- "채팅 메시지" 계열 알림을 제외한 다른 모든 유형의 알림에는 "DR" 접두사가 붙지 않습니다.
- "채팅 메시지" 계열 알림의 전송 채널이 "디버그"에서 "시스템 메시지"로 변경됩니다. 앞으로는 "로그 필터" 창의 "알림" 탭에서 "시스템 메시지" 체크를 해제하여 관련 메시지를 걸러낼 수 있습니다. (모든 "채팅 메시지" 계열 알림이 "시스템 메시지" 채널을 통해 전송되는 것은 아닙니다.)
- "Dalamud 알림" 계열 알림은 ImGui로 그려진 인터페이스를 조작할 때 발생하는 피드백에만 사용됩니다.
- "채팅 메시지" 계열 알림은 게임 네이티브 인터페이스(플러그인이 자체 제작한 네이티브 인터페이스 포함)와 네이티브 시스템 메커니즘을 조작할 때 발생하는 피드백에 집중적으로 사용됩니다.
- "콘텐츠 기믹" 계열 알림은 특별한 강조가 필요한 극소수의 피드백(사전에 명확히 고지된 오락성 요소 포함)에만 사용됩니다.
- "Windows 트레이 알림" 계열 알림은 장시간 자동화나 특별히 긴급하여 백그라운드 알림이 필요한 상황에 사용됩니다. 해당 알림 역시 게임이 백그라운드에 있거나 게임이 15초 동안 아무런 키 입력을 받지 못한 경우에만 전송됩니다. 일반적으로 다른 유형의 알림도 같은 내용을 함께 전송합니다.
- "플로팅 토스트" 계열 알림의 적용 상황은 "채팅 메시지" 계열 알림과 대체로 일치하지만, 구체적인 사용은 같은 종류의 게임 네이티브 시스템 메커니즘이 어떻게 사용되는지를 많이 참고하여 모방함으로써 네이티브 메커니즘에 더 가깝게 만듭니다.
- "Windows 시스템 소리" 계열 알림(부저 포함)은 특별한 강조가 필요한 극소수의 피드백(사전에 명확히 고지된 오락성 요소 포함)에만 사용됩니다.

## 신규 모듈

### 「임무 다시하기」 자동 재개 [시스템]

저장 데이터가 있는 경우, 로그인 시 혹은 콘텐츠 퇴장 후 임무 다시하기을 자동으로 재개합니다.

### 제한 없는 매크로 아이콘 [인터페이스]

*추천 모듈*

/pdr micon <아이콘 ID> 명령을 사용하여 매크로 아이콘을 원하는 아이콘으로 변경할 수 있습니다.

### 분해 UI 최적화 [인터페이스]

*추천 모듈*

'분해' UI을 최적화하여 분해 시 숙련도 정보 표시 기능을 추가하고, 아이템 일괄 분해를 지원합니다. '아이템 도움말' 화면에 상세한 아이템 분해 정보 표시 기능을 추가합니다. 아이템을 수동으로 분해할 때 자동으로 확인됩니다.

## 삭제된 모듈

### *자동 아이템 분해 [인터페이스]

기능이 이전되었으므로 새 모듈 "'분해' UI 최적화"를 사용하십시오.

## 모듈 수정

### 터보 클릭 [시스템]

- "게임패드 모드"에서 정상적으로 사용할 수 없던 문제를 수정했습니다.
- "대기 시간" 설정 항목을 추가했습니다. 이 시간 이상 길게 누르면 반복 클릭이 시작되며, 0이면 대기하지 않습니다.

### 불필요한 팝업 자동 숨김 [인터페이스]

- 모듈을 비활성화한 후 일부 창이 다시 나타나던 문제를 수정했습니다.

### 자동 따라가기 개선 [시스템]

- "콘텐츠 내에서만 활성화" 설정 항목을 추가했습니다. 기본값은 비활성화입니다.

### 아이템의 NPC 상점 정보를 표시합니다 [인터페이스]

- "NPC 상점 [사용처]" 창에 아이템 개요 정보를 더 이상 표시하지 않습니다.
- "NPC 상점 [사용처]" 창에서 "장터" 버튼을 클릭할 수 없던 문제를 수정했습니다.
- 페이지 넘김 컴포넌트의 외형과 위치를 조정했습니다.
- 열기 로직을 최적화했습니다.
- 아이템 아이콘 모두 우클릭 메뉴를 열 수 있게 되었습니다. 따라서 "장터" 버튼도 제거했습니다.
- "장터" 버튼이 제거됨에 따라, "NPC 상점 [사용처]" 창에서 원래 독립된 행이었던 비용 상세가 아이템 이름과 같은 행에 수평 오른쪽 정렬로 표시됩니다.
- 상점 목록의 상호작용 로직을 조정하여, 좌클릭하면 지도를 바로 열고 우클릭하면 메뉴가 열려 "가장 가까운 거점으로 이동"을 선택할 수 있습니다.
- 이제 상점 목록 표시가 지역별로 정렬됩니다.
- "아이템 상세 정보" 창에 표시되는 상점 정보와 열린 창 안에 표시되는 상점 정보가 일치하지 않던 문제를 수정했습니다.
- 모든 전제 모듈을 제거했습니다.
- 고품질 아이템의 "아이템 유지" 창에 상점 정보가 표시되지 않던 문제를 수정했습니다.
- 이제 "아이템 상세 정보" 창 안의 원래 "상점 판매" 정보를 항상 삭제하여 창을 간소화하고 중복을 피합니다.

### 빠른 전송 패널 [인터페이스]

- 임무 오브젝트 판정 로직을 최적화했습니다.
- 임무 오브젝트로 전송할 때 더 높은 위치로 보정될 수 있던 문제를 수정했습니다.
- vnavmesh 경로 탐색 로직을 제거했습니다.
- 확정된 대상 오브젝트로 전송할 때 대상과 겹치지 않게 되었습니다.
- 임무 오브젝트와 상호작용할 때 자동으로 선택됩니다.
- 이제 vnavmesh가 활성화되어 있으면 모든 전송 가능 지점의 위치가 이를 거쳐 보정됩니다.
- "상호작용 방식 최적화" 모듈을 함께 사용할 수 있는 모듈로 추가했습니다. 활성화하면 상호작용 가능 거리 판정이 조정됩니다.

### 퀵 채팅 패널 [인터페이스]

- 스크롤바가 자동으로 숨겨지지 않던 문제를 수정했습니다.

### 퀵 단골 거래 정보 화면 [인터페이스]

- 우클릭 메뉴 구현 방식을 조정했습니다. 설정에 따라 메뉴 항목에 "DR" 접두사가 표시될 수 있습니다.

### 장터 게시판 검색 결과 자동 새로고침 [시스템]

- 이제 로그아웃 시 장터 데이터를 자동으로 비워, 데이터센터를 넘어 다시 로그인한 후 장터 데이터를 가져오지 못할 수 있던 문제를 수정했습니다.
- 무료 체험 상태에서도 장터 데이터 요청을 반복 재시도하던 문제를 수정했습니다.

### 어디서든 장터 게시판 [인터페이스]

- 이제 무료 체험 상태에서는 로컬 장터 데이터를 요청하지 않고, 항상 Universalis에서 가져온 데이터를 표시합니다.
- 수동으로 지역을 전환한 후 서버가 자동으로 전환되지 않던 문제를 수정했습니다.
- "아이템 상세 정보" 창에 표시되는 "일일 판매량" 수치가 포맷되지 않던 문제를 수정했습니다.

### 빠른 서버 텔레포트 명령어 [인터페이스]

- (중국 서버 한정) 인터페이스 제목을 조정했습니다.

### 제작 수첩 UI 최적화 [제작 및 채집]

- "제작 절차" 창 안의 우클릭 메뉴가 "제작 수첩" 창이 닫힌 상태에서 열리지 않던 문제를 수정했습니다.

### 낚시터 경계 자동 해제 [제작 및 채집]

- "추가 텍스트 명령어"가 이제 매크로 명령 형태로 감싸져 실행됩니다.
- "추가 텍스트 명령어"의 잘못된 도움말 정보를 수정했습니다.
- 설명을 조정했습니다.
- 알림 메시지 텍스트와 외형 스타일을 조정했습니다.
- 설정 화면에 "전제 조건"을 추가하여 실행에 필요한 임무를 표시합니다.

### 집사 수행 자동화 [인터페이스]

- "출품 시 가격 자동 변경" 설정 항목의 표시 텍스트를 "출품 가격 자동 설정"으로 변경하고 관련 안내 정보를 추가했습니다.
- "한 번에 출품 수" 설정이 적용되지 않던 문제를 수정했습니다.
- "집사 목록" 창 옆의 플로팅 창에서는 "출품 가격 자동 설정"을 설정할 수 없게 되었습니다.
- "자동 출품" 설정 항목을 추가했습니다. 아이템을 출품할 때 표시되는 "가격 변경" 창의 "결정" 버튼을 자동으로 클릭합니다.
- "출품 목록" 창 옆의 플로팅 창 오른쪽 위에 "설정" 버튼을 추가하여 클릭하면 설정 창을 열 수 있습니다. 기존 "가격 기록 초기화" 텍스트 버튼은 오른쪽 위의 아이콘 버튼이 되었습니다.
- 우클릭 메뉴 분석이 "출품 목록" 창을 지원하게 됨에 따라, 이제 가격 변경 관련 자동 작업이 완료된 후 또는 "가격 변경" 창이 닫힐 때 "어디서든 장터 게시판" 모듈 창이 자동으로 닫힙니다.
- 창을 닫을 때 일부 리소스가 정리되지 않던 문제를 수정했습니다.

### NPC 대화 자동 스킵 [시스템]

- 로직을 완전히 재구성하여 더 저수준의 구현 방식을 사용했고, 더 많은 상황을 커버하며 버전 업데이트 시 무효화될 가능성이 낮아졌습니다.
- 설명을 조정했습니다.

### 스킵 제한 영상 강제 스킵 [시스템]

- 폴백 스킵 로직을 최적화하여 더 저수준의 구현 방식을 채택했습니다.
- 관찰형 컷신을 자동 선택할 때 해당 상태에 두 번째로 진입할 때부터 자동 완료되지 않던 문제를 수정했습니다.
- 설정 화면 그리기 로직을 최적화했습니다.

### 컨텐츠 자동 퇴장 [콘텐츠]

- 현재 콘텐츠 임무 완료 시의 자동 퇴장 동작을 수동으로 지정하는 `/pdr autoleaveduty` 명령을 추가했습니다. 수동 지정 동작은 설정보다 우선합니다.
    - `/pdr autoleaveduty None`: 수동 지정한 자동 퇴장 동작을 해제합니다.
    - `/pdr autoleaveduty InstantLeave`: 콘텐츠 임무 완료 시 즉시 자동 퇴장합니다.
