## 본체 변경

- 플러그인과 의존 라이브러리의 서비스 로딩 방식을 전면 개편하여 의존성 주입 방식으로 전환했습니다. 안정성과 안전성이 크게 향상되었습니다.
- 플러그인과 의존 라이브러리의 서비스 수명 주기를 전면 개편하고 단계별 처리 방식을 전반적으로 적용했습니다. 이제 언로드 시 자체 작업을 먼저 중지하고 백그라운드 작업을 취소한 뒤, 작업이 끝날 때까지 기다렸다가 엄격한 역순으로 리소스를 해제합니다.
- 초기화 및 언로드 과정의 많은 작업을 게임 메인 스레드 밖으로 옮겨 게임 끊김을 방지했습니다.
- 언로드 중 어느 단계에서든 예외가 발생하면 전체 언로드가 중단되던 문제를 수정했습니다.
- 이제 초기화 중 어느 단계에서 실패하더라도 완전히 롤백하여 리소스가 남지 않도록 했습니다.
- 플러그인 언로드 중 모듈 콜백과 정리 처리의 실행 시점 때문에 중지 중이지만 아직 해제되지 않은 관리자에 접근하여 예외가 발생하던 문제를 수정했습니다.
- 플러그인, 의존 라이브러리 및 모듈에서 게임 메인 스레드로 실행해야 하는 작업을 위한 작업 스케줄러를 도입했습니다. 1밀리초의 시간 예산에 따라 작업을 이후 프레임으로 자동 분배하여 게임 끊김을 방지합니다.
- 모듈 관리 로직을 전면 개편했습니다. 이제 통합 대기열로 모듈 활성화, 언로드, 재설정 및 다시 불러오기를 조정하여 디버깅하기 어려운 실행 중 문제를 방지합니다.
- 이제 모듈을 일괄 조작할 때 설정을 한 번만 저장하여, 과도한 파일 시스템 작업으로 시스템이 끊기거나 저장에 실패하는 문제를 방지합니다.
- 모든 모듈을 위한 내부 인덱스를 추가하여 모듈 검색 속도를 크게 높였습니다.
- 모듈 상태 변경 알림을 모아서 보내도록 변경하고, 대기 중 지속적으로 폴링하던 로직을 제거하여 불필요한 리소스 사용을 줄였습니다.
- 온라인 인증 시스템과 모듈 관리 시스템 사이에 취소 신호를 전달하여 실행 시점에 따른 문제를 방지합니다.
- 온라인 인증으로 발생하는 모듈 다시 불러오기와 모듈 관리 시스템의 모듈 초기화 또는 수동 다시 불러오기를 내부 신호로 조정하여 서로 엇갈려 실행되지 않도록 했습니다.
- 모듈을 완전히 다시 불러온 뒤 모든 세대의 가비지 수집을 강제로 실행하던 로직을 제거하여 게임 끊김을 방지했습니다.
- 다른 모듈의 선행 모듈로 지정된 모듈은 이제 해당 모듈들보다 반드시 먼저 불러옵니다.
- 모듈 정리용 델리게이트를 인스턴스 생성 시 미리 준비하고 인터프리터 방식으로 실행하도록 변경하여, 초기화 시 동적 메서드 생성과 컴파일이 집중되지 않도록 했습니다.
- 모듈 언로드 중 어느 단계에서든 예외가 발생하면 전체 언로드가 중단되던 문제를 수정했습니다.
- 모듈 인스턴스 생성 및 초기화 과정에서 중복되는 형식 검색과 불필요한 기본 객체 할당을 크게 줄였습니다.
- 모듈 개발용 파일 동기화에서 변경되지 않은 파일을 건너뛰어 불필요한 파일 시스템 작업을 방지합니다.
- Proton 등 Windows 글꼴 지원이 불완전한 Wine 환경에서 글꼴을 가져올 때 오류가 자주 발생하던 문제를 수정했습니다.
- 시스템 드라이브가 C:가 아니거나 기본 글꼴 설치 경로를 수동으로 변경했을 때 많은 시스템 글꼴을 가져오지 못하던 문제를 수정했습니다.
- 글꼴 검색 시 레지스트리도 확인하도록 하여 더 완전한 글꼴 목록을 가져올 가능성을 높였습니다.
- 글꼴 검색 및 선택에서 OpenType Collection(`.otc`)을 지원합니다.
- 글꼴 로딩 및 선택 로직을 개편하여 글꼴 패밀리를 선택할 수 있도록 했습니다.
- 프로젝트의 현지화 형식을 키-값 JSON에서 ID 기반 XLIFF로 전환했습니다.
- 현지화 리소스의 클라우드 동기화를 개선하여 이후 버전의 문자열을 잘못 가져오지 않도록 했습니다.
- 우클릭 메뉴 분석에서 이제 "부대 금고" 창을 지원합니다.
- 공통 아이템 입수처 및 상점 데이터에서 제작자용·채집가용 화폐를 석판 계열 화폐로 잘못 해석하던 문제를 수정했습니다.
- 게임 내 월드 좌표와 화면 좌표 사이의 변환 로직을 전면 개편했습니다. 활성 카메라가 아닌 대상 시스템에 캐시된 투영 행렬을 잘못 사용하여 좌표가 미세하게 흔들리고 화면 표시가 떨리던 문제를 해결했습니다.
- 모듈 미리보기 이미지가 한 장일 때와 여러 장일 때의 동작 및 표시 방식을 통일했습니다.
- 모든 모듈 미리보기 이미지를 WebP 형식으로 변경하여 파일 크기를 크게 줄이고 로딩 속도를 높였습니다.
- "기기 인증 자격 증명"을 지원 중단 예정으로 표시했습니다. 계속 사용 중이라면 셀프서비스 인증에서 다른 유형의 자격 증명으로 변경할 수 있습니다.
- 자격 증명 복사 버튼에 명확한 도움말을 추가하여 셀프서비스 인증 절차를 이해하기 쉽게 했습니다.

    - 성능 부하를 크게 줄였습니다.
    - 표시 문구를 "투영 세트 관리자에 저장"으로 변경했습니다.
    - 텍스트 버튼을 원형 아이콘 버튼으로 변경하여 기본 UI에 더 잘 어울리도록 했습니다.
    - 저장 성공 시 알림 대신 채팅 메시지를 보내도록 변경했습니다. 메시지를 클릭하면 투영 세트 관리자 창을 바로 열 수 있습니다.

### 전체 외형 장비 자동 입어보기 [인터페이스]

- 설명을 수정했습니다.
- 구현 로직을 전면 개편하여 더 낮은 수준에서 처리하도록 변경했습니다.
- "모두 입어보기" 버튼을 제거했습니다. 대신 장비 우클릭 메뉴에 "* 모든 장비 입어보기" 항목을 추가했습니다.
- 원래 입어본 장비가 고품질일 때 전체 장비를 입어보면 일반 품질로 바뀌던 문제를 수정했습니다.
- 이제 전체 장비를 입어볼 때 입어보기 내용을 동시에 저장하지 않습니다.
- 안경을 입어볼 수 없던 문제를 수정했습니다.
- 주무기와 보조무기를 동시에 입어볼 수 없던 문제를 수정했습니다.

### 대상 정보 UI 최적화 [전투]

- 설명을 수정했습니다.
- 시전 텍스트의 기본 색상을 조정하여 게임 기본 UI와 더 비슷하게 보이도록 했습니다.

### 퀵 채팅 패널 [인터페이스]

- 부속 창의 "설정" 탭 렌더링 로직을 전면 개편했습니다.
- "확대/축소" 설정을 추가했습니다. 기본값은 10입니다.
- "오프셋" 아래 "X"의 표시 문구를 "* 가로 오프셋"으로 변경했습니다.
- "오프셋" 아래 "Y"의 표시 문구를 "* 세로 오프셋"으로 변경했습니다.
- "메시지" 아래 새 메시지 입력란을 제거했습니다. 이제 "추가" 버튼을 클릭하면 별도의 입력 페이지가 열립니다.
- "메시지" 아래 각 항목 오른쪽의 "삭제" 버튼을 제거했습니다. 이제 메시지를 클릭하면 작업 메뉴가 열리며, 해당 메뉴에서 메시지를 삭제하거나 편집할 수 있습니다.
- "시스템 사운드" 아래 각 효과음 오른쪽의 메모 입력란을 제거했습니다. 이제 효과음을 클릭하면 작업 메뉴가 열리며, 해당 메뉴에서 메모를 편집할 수 있습니다.
- "시스템 사운드" 탭의 배치를 3열에서 2열로 변경했습니다.
- "특수 기호" 탭의 버튼 도움말을 더 명확한 안내 문구로 변경했습니다.
- 복사 알림을 Dalamud 알림에서 채팅 메시지로 변경했습니다.
- 설정을 변경해도 UI가 전혀 갱신되지 않던 문제를 수정했습니다.

### * "부대 금고" 창 개선 [인터페이스]

- 이름과 설명을 수정했습니다.
- 구현 로직을 전면 개편하여 더 낮은 수준에서 처리하도록 변경했습니다.
- 성능을 크게 개선했습니다.
- UI 요소가 흔들릴 수 있던 문제를 수정했습니다.

- 각 아이템 보관함 버튼의 우클릭 메뉴에 "* 기본 아이템 보관함으로 설정"을 추가했습니다.

![OptimizedFreeCompanyChest](/assets/Changelog/2.2.5.0/OptimizedFreeCompanyChest.webp)

### * 감정 표현 자동 반복 [시스템]

- 추천 모듈로 지정되었습니다.
- 이름과 설명을 수정했습니다.
- `/pdr remote` 명령어의 도움말을 수정했습니다.
- 반복 실행을 요청했을 때 감정 표현을 사용할 수 없는 상태라면, 사용할 수 있는 상태가 될 때까지 최대 10초 동안 기다립니다. 반복 실행을 시작한 뒤의 동작은 그대로 유지됩니다.
- 감정 표현 반복을 시작하거나 종료할 때 알림을 보냅니다.
- 기본 실행 간격을 2000밀리초 고정값에서 설정 항목으로 변경했습니다. "감정 표현" 창의 우클릭 메뉴에서 설정할 수 있으며, 기본값은 2000밀리초입니다.
- `/pdr remote` 명령어에 0 이하의 간격을 지정할 수 있던 문제를 수정했습니다.
- `/pdr remote` 명령어가 이름에 공백이 포함된 감정 표현을 해석하지 못하던 문제를 수정했습니다.
- 이제 `/pdr remote` 명령어에 잘못된 인수가 입력되면 오류 메시지를 표시합니다.
- 이제 `/pdr remote` 명령어 입력에서 전각 및 반각 큰따옴표를 자동으로 제거합니다.

### 탐험 수첩 자동 완료 [스크립트]

- 설명을 수정했습니다.
- 탐험수첩 목록을 개편하고 구성을 간소화했습니다. 시간 또는 날씨 조건이 있는 항목은 이제 시작하거나 종료될 때까지 남은 현실 시간도 표시합니다.
- 실행 상태 표시를 제거했습니다.
- 설정 UI에 여러 열 배치를 적용하여 전체가 지나치게 길어지지 않도록 했습니다.
- "항상 경로 탐색" 설정을 제거했습니다. 이제 경로 탐색이 필요한지 자동으로 판단합니다.
- 탐험수첩 목록에서 마우스를 올려 이미지를 표시할 때 해당 항목의 설명도 함께 표시합니다.
- 탐험수첩 목록에서 각 확장팩의 항목을 버전 번호 대신 확장팩 이름으로 분류하여 표시합니다.
- 탐험수첩 시간대를 확인할 때 종료 시각 11:59를 잘못하여 11:00으로 잘라내던 문제를 수정했습니다.
- 탐험수첩 시간대를 확인할 때 자정 이후 시간대가 누락되던 문제를 수정했습니다.
- 탐험수첩의 날씨를 확인할 때 현재 지역의 축제 상태와 정확하지 않을 수 있는 로컬 시스템 시간을 계산에 포함하여 잘못 계산하던 문제를 수정했습니다.
- 작업 실행 중 대상 항목의 완료 상태나 기록 조건이 변경되면 해당 항목의 남은 작업을 중단하고, 다음으로 수행 가능한 항목을 자동으로 시작하려고 시도합니다.
- 확장팩 이용 권한, 캐릭터 레벨 및 탐험수첩 퀘스트 개방 여부 확인을 보완했습니다.
