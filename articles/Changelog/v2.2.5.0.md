## 本体修改

- 完全重构了插件与依赖的服务加载模式，现在为依赖注入，极大提升了稳定性与安全性。
- 完全重构了插件与依赖的服务生命周期设计模式，普遍采取分段模式，现在在卸载时会先停止自身工作，取消后台任务，等待任务结束后再严格按照逆序释放资源。
- 将初始化与卸载的过程中的大量任务移出了游戏主线程，避免游戏卡顿。
- 修复了卸载过程中任意一步扔出的异常都会导致卸载被完全中断的问题。
- 现在初始化过程中任意一步失败都可以完整回滚，避免异常资源残留。
- 修复了插件卸载过程中因模块回调与清理相关机制的时序问题而获取到了正在停止但尚未释放的管理器进而导致扔出异常的问题。
- 为插件、依赖与模块中必须要运行在游戏主线程上的任务引入了完整的工作调度系统，按照 1 毫秒的时间预算自动将工作调度到后续帧，避免游戏卡顿。
- 完全重构了模块管理系统逻辑，现在通过统一队列协调模块启用、卸载、重置与重载，避免各类难以调试的运行期问题。
- 现在批量操作模块时只会保存一次配置，避免因大量文件系统操作造成系统卡顿或保存失败的问题。
- 为全部模块内部新建了索引，极大提升了模块查找速度。
- 模块状态变更时的通知现在合并发送，并移除了持续轮询等待逻辑，避免不必要的资源消耗。
- 在线验证系统与模块管理系统现在贯通取消信号，避免时序问题。
- 在线验证系统触发的模块重载与模块管理系统的模块初始化或手动重载现在通过内部信号协调，避免交错执行。
- 移除了完全重载模块后会强制触发一次全代垃圾回收的逻辑，避免游戏卡顿。
- 现在若一个模块成为了其他模块的前置模块，则该模块必定比对应模块更早加载。
- 现在将模块的清理委托提前至实例化时准备，并改用解释执行，避免初始化时集中生成和编译动态方法。
- 修复了模块卸载过程中任意一步扔出的异常都会导致卸载被完全中断的问题。
- 大量缩减了模块实例化与初始化过程中重复不必要的类型扫描与默认对象分配。
- 模块开发用文件同步机制现在会跳过未变化的文件，避免产生不必要的文件系统操作。
- 修复了字体获取逻辑会在 Proton 等对 Windows 字体支持不完整的 Wine 环境下频繁报错的问题。
- 修复了若系统盘不在 C 盘或曾手动修改过默认字体安装路径，则无法获取大量系统字体的问题。
- 字体扫描新增注册表相关逻辑，现在更有可能获取到更加完整的字体列表。
- 现在字体扫描与选择支持 OpenType Collection 字体集合（`.otc`）。
- 重构了字体加载选取逻辑，现在支持选择字体族。
- 项目本地化格式由“键值对 JSON”转为“基于 ID 的 XLIFF”。
- 优化了本地化资源云端同步功能，避免意外拉取到未来版本的字符串。
- 右键菜单解析现在支持“部队储物柜”界面。
- 修复了共通的物品来源与商店数据中，工票类货币被意外解析成神典石类货币的问题。
- 完全重构了游戏内世界坐标与屏幕坐标互转实现逻辑，消除了因错误使用目标系统缓存的投影矩阵而非活动相机缓存的投影矩阵导致坐标结果微小抖动进而显示“抽搐”的问题。
- 现在模块单张预览图与非单张预览图时的行为逻辑和外观样式保持完全一致。
- 模块预览图均改为使用 WebP 格式，以大幅降低文件体积与提高加载速度。
- 将“机器验证凭证”标注为了“即将废弃”，如仍在使用，可在自助验证处更换为其他类型的凭证。
- 为凭证复制按钮加上了明确的悬浮文本提示信息，以帮助理解自助验证流程。
