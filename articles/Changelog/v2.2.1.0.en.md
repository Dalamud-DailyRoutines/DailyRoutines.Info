## Core Changes

- Fixed an issue where the plugin would not attempt to obtain the "TID" again after failing to obtain it within the lifecycle.
- Added log output for when obtaining the "TID" fails.
- Fixed an issue where the "TID" failed because the same temporary file was used across processes.
- Optimized the timing of "AID" generation, so a fully logged-in character is no longer required.
- Fixed an issue where the shared cross-region travel process could get stuck at instance selection.
- Fixed an issue where, if the teleportation was interrupted manually during the shared cross-region travel process, a travel request could not be initiated again.
- Fixed a memory leak on plugin reload or module reload caused by a load context that could not be unloaded because some fields were retained.

## New Modules

### Auto Enable Quick Gathering [Craft & Gather]

*Recommended Module*

Automatically enable quick gathering in the gathering interface.

### Better /coll Command [System]

*Recommended Module*

Allow the names of items of interest in Collection to be the parameter for the command /coll and /collection.
(For example, /coll Mogpendium and /coll "Unending Codex")

### Auto Highlight Quest Object [Addon]

Automatically highlight all the objects of ongoing quests in the surrounding area for better perception.

## Module Changes

### Fast Object Interaction [Addon]

- The "Instance", "Aethernet shard", and "World Visit" components on the right side of the overlay can now be expanded or collapsed, keeping the window from becoming too long.

### Fast Teleportation Panel [Addon]

- Fixed an issue where the game occasionally crashed due to reading freed memory.
- Fixed an issue where data refresh failed because icons could not be read for some quests.
- Reworked the overall design logic, improving performance.

### Auto Very Easy Quest Battles [Duty]

- Adjusted the timing for determining whether to send notifications.

### Auto Adjust Signs [Combat]

- No longer a "Recommended Module".
- Fixed an issue where the size and position of some signs could not be set, or were reverted immediately.

### Batch Use Stackable Items [System]

- Fixed an issue where the process got stuck when the network was unstable.
- Process logs are now output.

### Set Time And Weather As Wish [Addon]

- Fixed an issue where restoring the time and weather could crash the game.

### Nearby Player Counter & Radar [General]

- Delayed the timing of zone player requests to avoid sending invalid requests when switching zones too quickly.

### Better Frame Rate Cap [System]

- Fixed an issue where setting the frame rate above the average frame rate lowered the frame rate.

### Auto Highlight Cursor [Addon]

- No longer a "Recommended Module".

### Auto Display Character Hitbox [Combat]

- No longer a "Recommended Module".

### Better Market Board [Addon]

- Reduced the interaction time of the "Hold For Batch Purchase" button from two seconds to one second.
- Fixed an issue where market data failed to render after a batch purchase.
- Fixed an issue where the "Mannequin" column was shown incorrectly in the market data of some items.

### Better Friend List [Addon]

- Reworked the appearance and interaction logic of the "Nickname & Comment" window. Some of the changes are as follows:
    - Added a confirmation prompt to the "Clear" button.
- Interaction in the "Previous Name Overview" and "Search Settings" windows no longer passes through to the "Friend List" window.
- Friends on other data centers can now also see the context menu items "Nickname & Comment" and "Retrieve Previous Names".

### Auto Refresh Market Search Results [System]

- Category changed from "Addon" to "System".

### Better Teleportation [Addon]

- Aetherytes and Aethernet shards now display the icon of the region they are located in when rendered in the list.
- The pagination header in the full Aetheryte list window now uses version icons.

### FC Member Manage Panel [Addon]

- Completely reworked the module implementation logic; all batch operations now use low-level game functions, greatly improving operation efficiency.
- Adjusted the module description text.
- Improved the appearance of the window.
- Fixed an issue where members' last online times were not displayed.
- Added a "Rank" column to the list.
- Added a confirmation prompt for dismissing free company members.
- The player is no longer drawn in the list to avoid accidental selection.
- Moved the name search function from the header to the outermost level.
- Right-clicking the "Rank" column header now filters free company members by a specific rank.
- Right-clicking the "Location / Last Online Time" column header now filters free company members by last online time.
- The module window now closes together with the "Free Company Members" window.

### Better World Visit [Addon]

- (Chinese servers only) Removed the "* Monitoring Travel Status" feature.

### Better Crafting Log [Craft & Gather]

- Changed the category from `Addon` to `Craft & Gather`.
- Adjusted the appearance of notification messages.
- Improved the logic for opening the "Solution Steps" window.
- Completely reworked the appearance and interaction logic of the "Solution Steps" window.

![OptimizedRecipeNote-Addon](/assets/Changelog/2.2.1.0/OptimizedRecipeNote-Addon.png)

- The batch crafting limit is now fixed at 99999.
- During auto crafting, action icons in the "Solution Steps" window now dim only after they have been used.
- Fixed an issue where changes to window element positions did not take effect immediately when the window was opened.

### Better Enmity List [Combat]

- Adjusted the appearance of the cast bar component.
- Adjusted the default outline color of cast text and HP text to match the native window.
- Text for interruptible actions now also has a red outline as a warning.

### Auto Gather In Island Sanctuary [Script]

- Fixed an issue where notification messages could still be sent outside the Island Sanctuary.

### Auto Retainer Routines [Addon]

- The ImGui overlay no longer covers the native window; most of the former overlay functions are now provided through context menus or native-style windows.
- Changed the behavior of the "Auto Adjust Price While Listing" setting. The native "Adjust Price" window still appears, but the price cannot be adjusted in it, only the number of items to sell; the automatic lookup of the current market price and the adjustment of the selling price according to the rules begin only after confirming in that window.
- The native "Compare prices." button now opens the "Better Market Board" module window.

### Leave Recruitment Then Join Another [Addon]

- Added a confirmation prompt for button clicks.
- Fixed an issue where the button did not appear immediately when the window was opened.
