## 본체 변경

- "반투명 하양" 이외의 색상 테마에서 드롭다운 라벨 텍스트 색상이 비정상적으로 표시되는 문제를 수정했습니다.
- 이제 현재 클라이언트에 적용할 수 없는 모듈은 불러오지 않습니다.
- 이제 인증을 마치기 전에는 인증이 필요한 모듈을 표시하지 않습니다.
- Wine 환경에서 알림을 보내는 모듈을 하나라도 켜 두면 알림을 보낼 때 게임이 충돌하는 문제를 수정했습니다.
- 현지화 문자열 파싱에 실패하면 예외가 그대로 밖으로 던져지는 문제를 수정했습니다.

## 추가된 모듈

### * 컨텐츠 퇴장 명령 [도우미]

*오늘의 추천 모듈*

"/pdr leaveduty" 명령을 추가해 임무에서 빠르게 퇴장할 수 있습니다.

### * 색상 테마 즉시 반영 [인터페이스]

*오늘의 추천 모듈*

게임에서 로그아웃하지 않고도 색상 테마 설정을 바로 적용할 수 있습니다.

(이 모듈은 특수하기 때문에, 색상 테마 즉시 반영을 지원하도록 네이티브 UI와 노드를 사용하는 다른 기능도 함께 폭넓게 리팩터링했습니다.)

### * 시전 중 이동 금지 [액션]

스킬 시전 중에는 이동을 자동으로 금지해 시전이 뜻하지 않게 끊기는 것을 막습니다.

## 삭제된 모듈

버전 업데이트마다 데이터를 관리해야 해서 드는 수고가 너무 컸고, 지금은 관리하는 사람도 없어 삭제했습니다.

## 모듈 변경

### 보물상자 자동 열기 [콘텐츠]

- 이제 내부 테스트 자격 증명이 없으면 기능은 솔로 상태에서만 작동합니다.

### 빠른 전송 패널 [인터페이스]

- 이제 내부 테스트 자격 증명이 없으면 기능은 이동 속도 감지가 없는 지역에서만 작동합니다.

### * "제작수첩" 창 개선 [인터페이스]

- 이름과 설명을 조정했습니다.
- 알림의 겉모습과 내용을 조정했습니다.
- 일괄 제작 시 "제작수첩" 창이 열려 있지 않으면 다시 엽니다.
- 일괄 제작 시 사용할 수 있는 재료를 자동으로 고릅니다.
- "제작 절차" 창에서 제작 횟수 기본값이 보유한 재료에 따라 동적으로 계산됩니다.
- "제작 절차" 창에서 해법이 도달할 것으로 예상되는 진행도와 품질을 표시합니다.
- "제작 절차" 창에 있던 별도의 "* 매크로 복사" 행을 없애고, 그 대신 스킬 미리보기 컨테이너 오른쪽 위에 버튼을 추가했습니다. 이 버튼을 누르면 메뉴가 열리고, 그 안에서 매크로를 골라 복사할 수 있습니다.

- 미리보기 이미지 두 장을 추가했습니다.

### 【청마도사】 청마법 활성 세트 불러오기 개선 [시스템]

- 이제 이름이 없는 유효 세트도 명령으로 불러올 수 있습니다.

### 차단 목록 개편 [시스템]

- 우클릭 메뉴의 일부 항목에 하위 메뉴 표시가 잘못 나타나는 문제를 수정했습니다.
- 1000건을 넘는 기록이 있는 공유 차단 목록을 끝까지 가져오지 못하는 문제를 수정했습니다.
- "차단 목록" 창 옆에 부착 창을 추가해 게임 기본 차단 목록을 빠르게 다룰 수 있습니다.
    - 기능 버튼 "* 무효 차단 목록 제거". "미지와의 해후"부터 "내일을 향한 이정표" 버전 기간에 구 계정 식별자 형식으로 기록되었으나 지금은 무효가 된 차단 목록 항목을 제거합니다.
    - 기능 버튼 "* 구 차단 목록 제거". "미지와의 해후" 이전 버전에서 캐릭터 식별자로 기록된 차단 목록 항목을 제거합니다.
    - 기능 버튼 "차단 목록 개편". 설정 창을 엽니다.
    - 기능 버튼 "* 모든 차단 목록 제거". 기록된 차단 목록 항목을 모두 제거합니다.
- "차단 목록" 창 왼쪽 위의 "차단 목록 개편" 버튼을 없앴습니다.
- 플레이어를 기본 차단 목록에 추가하는 우클릭 메뉴 항목을 더 이상 막지 않습니다.
- 공유 차단 목록 없이 로컬 차단 목록만 있을 때 로컬 차단 목록의 데이터가 처음 지역을 옮기거나 차단 목록을 고친 뒤에야 적용되는 문제를 수정했습니다.
- 플레이어를 차단 목록에 추가하거나 해제하면 그 플레이어의 이름 표시 텍스트와 캐릭터 표시 여부 같은 정보가 곧바로 바뀝니다.
- 로컬 차단 목록 정보를 고친 뒤에도 알림에 예전 정보가 표시될 수 있는 문제를 수정했습니다.
- 플레이어가 여러 차단 목록에 있으면 알림에 각 차단 목록의 정보가 빠짐없이 표시됩니다.
- 이제 공유 차단 목록에 참여할 때 대상 차단 목록이 없으면 빈 그룹을 만들지 않고 참여 실패를 알립니다.
- 일부 공유 차단 목록 작업에 실패 안내를 추가했습니다.
- 창에서 차단 목록 플레이어를 직접 추가할 때 자기 캐릭터 정보를 넣을 수 있는 문제를 수정했습니다.

### FPS 제한 설정 개선 [시스템]

- 설명을 조정했습니다.
- "/pdr fps" 명령에 쓸 수 있는 파라미터를 늘렸습니다.
    - 인수 없음: "* 프레임 제한" 창을 열거나 닫습니다.
    - `on`: 프레임 레이트를 제한합니다.
    - `off`: 프레임 레이트를 제한하지 않습니다.
    - `toggle`: 프레임 레이트 제한을 켜거나 끕니다.
    - `<프레임 수>`: 목표 프레임 수(1~32767 사이의 정수)를 설정하고 프레임 레이트를 제한합니다.
- "/pdr fps" 명령을 쓰면 알림을 보냅니다.
- 오버레이 안의 각 프레임 지표가 이제 현지화된 텍스트로 표시됩니다.
- 실제 지표가 아니므로 설정한 프레임 제한은 오버레이 안에 더 이상 표시하지 않습니다.
