## 본체 변경

- "투명한 흰색"이 아닌 색상 테마에서 드롭다운 컴포넌트의 라벨 텍스트 색상이 비정상적으로 표시되는 문제를 수정했습니다.
- 이제 현재 클라이언트에 적용되지 않는 모듈은 불러오지 않습니다.
- 이제 미인증 상태에서는 인증이 필요한 모듈을 표시하지 않습니다.

## 신규 모듈

### * 콘텐츠 퇴장 명령 [도우미]

*추천 모듈*

"/pdr leaveduty" 명령을 추가해 콘텐츠에서 빠르게 퇴장할 수 있게 했습니다.

### * 색상 테마 즉시 적용 [인터페이스]

*추천 모듈*

색상 테마 설정이 게임에서 로그아웃하지 않고도 즉시 적용됩니다.

(이 모듈은 특수하기 때문에, 네이티브 UI와 노드를 사용하는 다른 기능들도 함께 대규모로 리팩터링해 색상 테마의 즉시 적용을 지원하도록 했습니다.)

버전 업데이트마다 데이터를 관리해야 해서 드는 품이 너무 많고, 현재 유지 관리하는 사람도 없어 삭제했습니다.

## 모듈 변경

### 보물상자 자동 열기 [콘텐츠]

- 이제 * 내부 테스트 자격 증명이 없으면 기능은 솔로 상태에서만 적용됩니다.

### 빠른 전송 패널 [인터페이스]

- 이제 * 내부 테스트 자격 증명이 없으면 기능은 이동 속도 감지가 없는 지역에서만 적용됩니다.

### * "제작 수첩" 인터페이스 개선 [인터페이스]

- 이름과 설명을 조정했습니다.
- 알림의 외형과 내용을 조정했습니다.
- 일괄 제작 시, 현재 "제작 수첩" 창이 열려 있지 않으면 다시 엽니다.
- 일괄 제작 시, 사용 가능한 재료를 자동으로 선택합니다.
- "제작 절차" 창에서 열 때 제작 횟수의 기본값이 보유 중인 재료에 따라 동적으로 계산됩니다.
- "제작 절차" 창에 해석 결과가 도달할 것으로 예상되는 진행도와 품질이 표시됩니다.
- "제작 절차" 창 안의 별도 "* 매크로 복사" 줄을 제거했습니다. 그 대신 스킬 미리보기 컨테이너 오른쪽 위에 버튼을 추가했고, 클릭하면 메뉴가 열려 그 안에서 매크로를 선택해 복사할 수 있습니다.

![OptimizedRecipeNote-Addon](/assets/Changelog/2.2.4.0/OptimizedRecipeNote.png)

- 미리보기 이미지 2장을 추가했습니다.

### 【청마도사】 청마법 활성 세트 불러오기 개선 [시스템]

- 설명을 조정했습니다.
- 유효 스킬 세트 중 하나라도 이름이 없을 때 명령으로 불러오면 잘못된 유효 스킬 세트를 불러올 수 있는 문제를 수정했습니다.
- 이제 이름이 없는 유효 스킬 세트도 명령으로 불러올 수 있습니다.

### 차단 목록 개편 [시스템]

- 우클릭 메뉴의 일부 항목에 하위 메뉴 표시가 잘못 나타나는 문제를 수정했습니다.
- 1000건을 넘는 기록이 있는 공유 차단 목록을 완전히 가져오지 못하는 문제를 수정했습니다.

### 빠른 서버 텔레포트 명령어 [시스템]

- 설명을 조정했습니다.
- 이제 항상 인터페이스 요소에 따라 크기를 동적으로 계산합니다.
- 이제 창 안의 각 서버 컴포넌트가 클라이언트에서 확인할 수 있는 서버 이동 상태를 실시간으로 가져와 표시합니다.
- 창의 수명 주기 관리 로직을 최적화했습니다.
- (국제 서버 한정) 일본 물리 데이터 센터 내에서 직접 서버 간 이동을 지원합니다.
