## 본체 변경

- Wine 환경 감지 방식을 최적화했습니다.
- '장치 인증 증명서' 관련 인증 획득 컴포넌트를 업데이트했습니다.
- 온라인 인증 연결이 시스템 프록시를 강제로 우회하도록 하던 메커니즘을 제거했습니다.
- 초기화 로딩 우선순위를 높였습니다.
- 업데이트 내역 창에서 너무 긴 이미지가 표시 영역을 벗어나는 문제를 수정했습니다.
- '일반'에 설정 항목 '온라인 인증 시 프록시 무시'를 추가했습니다. 온라인 인증 요청을 보낼 때 시스템 프록시 설정을 무시하고 인증 서버에 직접 연결합니다. 가상 네트워크 어댑터 등 전역 투명 프록시를 사용하는 경우 이 옵션은 적용되지 않습니다. 기본값은 비활성화이며, 이전 버전과 동일하게 동작합니다.
- '일반'에 설정 항목 '활성화 상태에서 조작 없을 시 알림 표시 시간 (밀리초)'를 추가했습니다. 조작이 없는 시간이 설정값에 도달하면 게임이 활성화 상태여도 Windows 트레이 알림을 표시합니다. 0으로 설정하면 게임이 백그라운드에 있을 때만 알림을 표시합니다. 기본값은 15000밀리초이며, 이전 버전과 동일하게 동작합니다.
- 우클릭 메뉴 분석이 '아이템 검색' 창을 지원합니다.
- '일반'의 설정 항목 '중단용 단축키' 도움말 텍스트를 조정했습니다.
- '중단용 단축키'를 표시할 때 현재 게임 조작 모드에 따라 키보드 키 또는 게임패드 키 설정값을 각각 표시합니다.
- 디버그 창이 캐시 모듈을 제때 정리하지 않아 '모듈 다시 불러오기' 후 기존 모듈 인스턴스를 회수할 수 없던 문제를 수정했습니다.
- JSON 변환기가 제때 정리되지 않아 어셈블리를 회수할 수 없던 문제를 수정했습니다.
- Newtonsoft.Json이 키-값 쌍 직렬화를 위해 동적 메서드 참조를 생성해 어셈블리를 회수할 수 없던 문제를 수정했습니다.
- 이제 '모듈 다시 불러오기'를 할 때마다 전체 가비지 컬렉션이 실행됩니다.
- 네이티브 창 주변에 붙는 모든 창의 구현 방식을 전면 재작성했습니다. 이제 게임 네이티브 자식 창 시스템으로 완전히 구현합니다. 구현 방식이 달라 외관과 조작 방식도 이전 버전과 다릅니다.
    - 제목 표시줄을 표시하지 않습니다.
    - 이 창들을 개별적으로 포커스하거나 조작할 수 없습니다.
    - 이 창들을 개별적으로 닫을 수 없습니다.
    - 이 창들을 닫아도 붙어 있는 대상 창이 함께 닫히지 않습니다.
    - 붙는 창은 대상 창의 배율을 상속합니다.
- 일부 네이티브 스타일 창에서 기본 앵커가 지정되지 않아 노드 위치가 흔들리는 문제를 수정했습니다.
- 모듈 카드의 '미리보기 이미지' 그리기를 전면 재작성했습니다. 여러 장의 미리보기 이미지가 있으면 완전한 캐러셀 컴포넌트로 렌더링하며 빠른 전환을 지원합니다.
- 콘텐츠 안에서도 상향 패킷 우선순위가 올라가던 문제를 수정했습니다.
