## 本体の変更

- モジュールカードに「推奨」タグを追加し、「推奨モジュール」を示せるようにしました。
- インターフェイスのフォントサイズを変更する際、フォントの再構築が頻繁に発生する問題を修正しました。
- 記録された過去のバージョンが有効なバージョンとして解析できない場合、メインインターフェイスを開けない問題を修正しました。
- バージョン更新インターフェイスの外観スタイルを全面的に再構築しました。更新履歴の表示を追加しました。
- 初回セットアップインターフェイスを追加しました。ここで主な仕様の設定とプラグインの概要の確認ができます。初回セットアップが完了するまで、モジュールは一切読み込まれません。
- 混同を避けるため、モジュール情報内の「推奨モジュール」を「連携可能モジュール」に名称変更しました。
- 設定インターフェイスの外観スタイルを再構築し、単一列レイアウトに変更してテキストをより完全に表示できるようにしました。
- 設定項目「ジャンプ状態修正」を削除しました。

## 追加モジュール

### 不整合な魔獣編成を自動的に禁止します。 [コンテンツ]

*推奨モジュール*

「闘獣練」において、現在の魔獣編成が3体未満の場合は、挑戦を開始することはできません。また、呼び笛に魔獣が設定されていない場合は、誤操作を防ぐため、戦闘を開始することはできません。

### 石工の理と老農の知を自動的に阻止する [製作・採集]

*推奨モジュール*

「理知興起実行可」ステータス中、GPの無駄消費を防止するため、アビリティ「石工の理」および「老農の知」の自動実行を無効化します。

### 「/pvpaction」コマンドの機能拡張 [アクション]

*推奨モジュール*

「/pvpaction（/pvpac）」コマンドで、コンボ専用技など普段ホットバーにセットできないアクション名も指定できるようになりました。 （例：/pvpaction グレアジャ、/pvpaction ライオットソード）

### 「PvP専用アクション」 UI の改善 [インターフェイス]

*推奨モジュール*

「PvP専用アクション」 UI を改善し、従来ホットバーに登録できなかったアクションも対戦専用ホットバーへドラッグ＆ドロップで設定できるよう変更しました。

## モジュールの変更

### ディアデム諸島自動採集 [スクリプト]

- ゲームデータの更新が間に合わないため、誤った終点へ経路探索される問題を修正しました。

### 【BLU】青魔法アクティブセットの読み込み改善 [システム]

- アクティブセットを読み込む際、対応するホットバーが自動的に読み込まれない問題を修正しました。

### クイックパネルのUI最適化 [インターフェイス]

- モジュールのロジックを全面的に再構築し、各種操作ロジックと挙動がホットバーと完全に一致するようになりました。具体的には、ロック中は以下の通りです：
    - インターフェイスをドラッグできず、マウスカーソルは手の形のドラッグアイコンに変わりません。
    - Esc キーでインターフェイスを閉じることができず、キー入力は通常どおり他のゲームロジックに透過します。
    - 各スロットをドラッグして入れ替えることができません。
    - スロットの右クリックメニューを開くことができません。
- モジュールの説明テキストを調整しました。
- ロックボタンの位置を調整しました。
- ロックボタンのホバーテキストヒントを削除し、ホットバーと一致させました。

### ズーム距離カスタマイズ [システム]

- コンテンツ「闘獣練」の戦闘エリアに入った後に設定が無効になる問題を修正しました。

### 潜水艦自動回収 [インターフェイス]

- ログイン後、探索状況の通知メッセージが速やかに送信されない問題を修正しました。

### マテリア自動装着 [インターフェイス]

- ウェブサイト最新版のエクスポートデータに対応しました。
- モジュールインターフェイスの外観スタイルと操作ロジックを全面的に再構築しました。

### ターボクリック機能 [システム]

- ゲームパッド操作モード時に、ゲームパッドでインターフェイスをスクロールできなくなる問題を修正しました。
- 設定項目「トリガーキー」を削除しました。
- 設定インターフェイスの外観スタイルを調整しました。

### クイック相乗り [システム]

- 相乗り可能なPTメンバーを右クリックした際、右クリックメニューを開いてから閉じる方式から、右クリックメニューの表示自体を直接阻止する方式に変更しました。
- 最初の位置を固定で渡してサーバーに空きを自動割り当てさせる方式から、ローカルで空きを直接取得して渡す方式に変更しました。
- 一部の相乗り条件を満たさない場合でも、右クリックメニューの表示を阻止しなくなりました。
- 通知メッセージを追加しました。
- モジュールの説明テキストを調整しました。
- コマンド「/pdr ridepillion」を追加しました。使用すると、周囲のPTメンバーのマウントに自動で相乗りします。

### クエストバトルをVery Easyに設定 [戦闘]

- 通知メッセージが重複して送信される問題を修正しました。
- 通知メッセージの内容と外観スタイルを調整しました。
- モジュールの説明テキストを調整しました。

### 自動的に低レベルスキルへ置き換え [アクション]
