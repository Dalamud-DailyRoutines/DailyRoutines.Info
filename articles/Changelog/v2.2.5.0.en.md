## Plugin Changes

- Completely refactored service loading for the plugin and its dependencies to use dependency injection, greatly improving stability and safety.
- Completely redesigned service lifecycles for the plugin and its dependencies around a phased approach. During unloading, services now stop their own work, cancel background tasks, wait for those tasks to finish, and then release resources in strict reverse order.
- Moved many initialization and unloading tasks off the game's main thread to prevent stuttering.
- Fixed an issue where an exception at any stage of unloading would interrupt the entire unloading process.
- Initialization can now be fully rolled back if any stage fails, preventing resources from being left behind.
- Fixed an issue where the timing of module callbacks and cleanup during plugin unloading could cause access to managers that were stopping but had not yet been disposed of, resulting in exceptions.
- Introduced a complete work scheduler for tasks in the plugin, its dependencies, and modules that must run on the game's main thread. Work is automatically deferred to later frames according to a 1 ms time budget to prevent stuttering.
- Completely refactored module management. A unified queue now coordinates enabling, unloading, resetting, and reloading modules to prevent runtime issues that are difficult to debug.
- Batch module operations now save the configuration only once, preventing system stuttering or save failures caused by excessive file system operations.
- Added an internal index for all modules, greatly improving lookup speed.
- Module state change notifications are now batched, and continuous polling has been removed to avoid unnecessary resource usage.
- Cancellation signals now propagate between online verification and module management to prevent timing issues.
- Module reloads triggered by online verification are now coordinated with module initialization and manual reloads through internal signals to prevent interleaved execution.
- Removed the forced full-generation garbage collection after a complete module reload to prevent stuttering.
- A module required by other modules is now always loaded before those modules.
- Module cleanup delegates are now prepared during instantiation and use interpreted execution, avoiding a burst of dynamic method generation and compilation during initialization.
- Fixed an issue where an exception at any stage of module unloading would interrupt the entire unloading process.
- Greatly reduced redundant type scanning and unnecessary default object allocations during module instantiation and initialization.
- File synchronization for module development now skips unchanged files to avoid unnecessary file system operations.
- Fixed frequent font lookup errors in Wine environments with incomplete Windows font support, such as Proton.
- Fixed an issue where many system fonts could not be found if the system drive was not C: or the default font installation path had been changed manually.
- Font scanning now also checks the registry, making it more likely to retrieve a complete font list.
- Font scanning and selection now support OpenType Collection (`.otc`) files.
- Refactored font loading and selection to support selecting font families.
- Migrated the project's localization format from key-value JSON to ID-based XLIFF.
- Improved cloud synchronization of localization resources to avoid accidentally downloading strings from future versions.
- Context menu parsing now supports the Company Chest window.
- Fixed an issue where scrip currencies were incorrectly interpreted as tomestone currencies in shared item source and shop data.
- Completely refactored conversion between in-game world coordinates and screen coordinates. This eliminates the slight coordinate jitter and resulting visual twitching caused by incorrectly using the projection matrix cached by the targeting system instead of the active camera.
- Module previews now have consistent behavior and appearance whether there is a single image or multiple images.
- Converted all module preview images to WebP to greatly reduce file sizes and improve loading speed.
- Marked Machine Verification Credentials for upcoming deprecation. If you still use one, you can replace it with another credential type through self-service verification.
- Added explicit tooltips to credential copy buttons to help explain the self-service verification process.

- The `/pdr remote` command now automatically strips full-width and half-width double quotation marks from input.
