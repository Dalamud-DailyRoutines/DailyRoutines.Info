## Framework Changes

- Some incorrect localization within the authentication interface has been amended.
- Test worlds that are not actually available has been excluded on the Traditional Chinese data center.

## New Modules

### Chrysalis Helper [Duty]

*Recommended Module*

Automatically mark orbs to be soaked according to the vulnerability status on the character in the duty "Chrysalis".

### Persistent Targeting [System]

*Authentication Required*

Allow to keep targeting even when the target is out of range and to target via the Focus Target interface. Targeting won't be canceled as long as the data related to the target is still recorded in memory. 

## Module Changes

### Auto FATE [Script]

- New "Break" feature, to regularly take a break after farming in order to simulate human behaviour. Disabled by default.
- Now all the unreachable aethernet shards under normal circumstances have been excluded.
- An issue that the character was unable to dismount after flying to a collection FATE has been fixed.
- Now it would perform stance control only when necessary stance actions have been unlocked.

### Occult Crescent Helper [Duty]

- An issue of unexpected remaining time for "Tower of Magic" has been fixed.
- Now it will perform mount checks based on distance dynamically during navigation.
- An issue that it may get stuck while approaching an occult aetheryte has been fixed.
- Now the distance threshold that the character would prefer mounting rather than running has been decreased from 50 to 40.
- Now the character will target FATE enemies only after entering the range.

### Neverreap Helper [Duty]

- Now it no longer requires authentication.

### Better FATE Progress UI [Interface]

- The logic has been streamlined.
- Now it would request data only after login.

### Auto Adjust Battle Effect Visibility [Combat]

- Now enabled duty categories will be highlighted in green in the "In Duty" tab for better perception.
- Duty category IDs have been removed in the "In Duty" tab.

### Better World Visit [System]

- The logic has been improved and streamlined.
- Now all the notifications are created using vanilla game assets.
- Now notifications are more detailed.
- Now a navigation process supported by the navigation system within Daily Routines will be performed before world visiting if a world-visit request is initiated in zones that world-visit requests are unavailable.
- A confirmation has been introduced before returning to Home World in order to prevent misclicking.
    - New configuration option "Skip Return Confirm", to skip the return confirmation.

### No Mount Disabling [System]

- An issue that the module didn't work due to new offsets has been fixed.

### Auto Summon Companion [Combat]

- The configuration options "Send Notification" and "Send TTS" have been removed.
- The notification appearance has been adjusted.
- Now it would summon the companion only after the feature has been unlocked.

### Auto Store To Armoire [Interface]

- Now gears in Armoury have been excluded.
