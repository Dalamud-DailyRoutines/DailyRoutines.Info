## Core Changes

- Added a "Recommended" tag to module cards to mark "recommended modules".
- Fixed an issue where font rebuilding was triggered frequently while adjusting the UI font size.
- Fixed an issue where the main window could not be opened when the recorded previous version could not be parsed as a valid version.
- Completely reworked the appearance of the update window. A changelog display has been added.
- Added a first-time setup window, in which key configuration items can be configured and the plugin can be learned about. No modules are loaded until the first-time setup is complete.
- To avoid confusion, "Recommended Module" in module information has been renamed to "Combo Module".
- Reworked the appearance of the settings window, changing it to a single-column layout so that text is displayed more completely.
- Removed the "Correct Jump State" setting.

## New Modules

### Auto Check Beast Settings [Duty]

*Recommended Module*

Automatically prevent the character from commencing The Crucible of the Unbroken if there're less than 3 beasts available, and engaging in combat in The Crucible of the Unbroken if there's a battlehorn unassigned.

### Auto Block Solid Reason And Ageless Words [Craft & Gather]

*Recommended Module*

Automatically block "Solid Reason" and "Ageless Words" if the status "Eureka Moment" has been applied to the character.

### Better /pvpac Command [Action]

*Recommended Module*

Allow an action that cannot be assigned to a hotbar to be the a parameter for the command /pvpac and /pvpaction.
(For example, /pvpac "Glare IV" and /pvpac "Riot Blade")

### Better PvP Role Action [Addon]

*Recommended Module*

Provide a better PvP Role Action widget, allowing an action that cannot be assigned to a hotbar to be assigned to the widget.

## Module Changes

### Auto Gather In Diadem [Script]

- Fixed an issue where the character could pathfind to a wrong destination because the game data was not updated in time.

### Better BLU Active Set [System]

- Fixed an issue where the corresponding hotbar was not loaded automatically when reading the active set.

### Better Command Panel [Addon]

- Completely reworked the module logic; all operations and behaviors are now fully identical to those of hotbars. Specifically, while locked:
    - The window cannot be dragged, and the mouse cursor does not change to the hand-shaped drag icon.
    - The window cannot be closed with the Esc key, and the key input passes through to other game logic as usual.
    - Slots cannot be dragged to swap with each other.
    - The slot context menu cannot be opened.
- Adjusted the module description text.
- Adjusted the position of the lock button.
- Removed the hover tooltip of the lock button to keep it consistent with hotbars.

### Custom sight distance [System]

- Fixed an issue where the setting stopped working after entering the battle arena of "The Crucible of the Unbroken".

### Auto Collect Subaquatic Voyages [Addon]

- Fixed an issue where the exploration notification message was not sent in time after logging in.

### Auto Meld Materia [Addon]

- Adapted to the latest version of the export data from the website.
- Completely reworked the appearance and operation logic of the module window.

![AutoMateriaAttach-UI](/assets/Changelog/2.2.0.0/AutoMateriaAttach-UI.png)

### Auto Click Repeatedly [System]

- Fixed an issue where, in gamepad mode, the controller could not scroll through windows.
- Removed the "Trigger Key" setting.
- Adjusted the appearance of the configuration window.

### Better Ride Pillion [System]

- Right-clicking a party member whose mount can be ridden pillion now blocks the context menu from opening directly, instead of opening the context menu and then closing it.
- The free seat is now obtained locally and passed in, instead of always passing the first seat and letting the server assign a free one.
- The context menu is no longer blocked from opening when some pillion riding requirements are not met.
- Added notification messages.
- Adjusted the module description text.
- Added the command `/pdr ridepillion`, which automatically rides pillion on a nearby party member's mount.

### Auto Very Easy Quest Battles [Combat]

- Fixed an issue where notification messages were sent repeatedly.
- Adjusted the content and appearance of notification messages.
- Adjusted the module description text.

### Auto Replace Low Level Actions [Action]

- Added action replacements:
    - Blizzard IV → Blizzard
    - Fire IV → Fire

### Custom Map Mark [Addon]

- To avoid blocking the view, the button on the map window has been moved from the top right corner to the bottom right corner.

### Better Frame Rate Cap [System]

- Fixed an issue where the height of the "FPS Cap" window jittered.
- Adjusted the position of the current FPS text in the "FPS Cap" window to avoid overlapping.
- Completely reworked the frame rate cap mechanism, making the cap and measurement more accurate and stable.

### Auto Retainer Routines [Addon]

- The market board window is now closed automatically when batch price adjustment is complete.
- The window now supports controller operation.

### Auto Expert Delivery [Addon]

- The window now supports controller operation.

### Better Phantom Job Repertoire [Addon]

- The window now supports controller operation.
- Adjusted the animation implementation to keep it consistent with native windows.

### Quickly Exchange Seals For Items [Addon]

- Completely reworked the implementation logic, greatly improving the exchange speed.
