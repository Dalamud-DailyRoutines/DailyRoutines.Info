---
title: OmenBot 隐私政策
---

最后更新：2026 年 2 月 20 日

本隐私政策说明 OmenBot（Discord 应用 ID `1262631779316269116`，以下简称“本应用”）在提供服务的过程中会收集哪些数据、如何使用这些数据、数据存放于何处，以及用户可以如何管理自己的数据。

本应用由 Daily Routines 开发者自行托管与维护，仅在自己的 Discord 服务器中运行，通过私信中的应用命令向用户提供服务。

## 收集的数据

本应用不读取、不存储任何 Discord 消息内容。全部数据来自用户主动执行应用命令时提交的信息，以及 Discord 随交互一并提供的身份标识。

| 数据 | 说明 |
| --- | --- |
| Discord 用户 ID | 所有本地记录的主键，用于把凭证与语言设置归属到具体用户 |
| Discord 用户名 | 用于后台命令识别与审核记录展示。用户名在每次验证或提交时刷新，始终为当前名称 |
| 语言偏好 | 用户通过 `/language` 选择的界面语言 |
| 游戏账号凭证 | 用户通过 `/verify` 提交的 Final Fantasy XIV 账号标识，用于向关联服务发放授权 |
| 凭证时间信息 | 凭证的验证时间、到期时间与下次验证时间 |
| 凭证更换冷却 | 记录最近一次凭证更换时间，用于限制更换频率 |
| 每日查询计数 | `/query-cid` 的当日调用次数，用于限流 |
| 赞助申请资料 | 用户通过 `/verify` 提交赞助时填写的作者名、平台名、订单号、截图链接，以及审核状态与处理结果 |
| 审计日志 | 管理操作与业务事件的记录，包含操作者 Discord 用户 ID、用户名与操作内容 |

关于服务器成员身份组：本应用申请了「服务器成员」特权 Intent，用途是读取用户在服务器中的身份组，据此判定可发放的凭证数量与有效期、是否为服务器助力者、应同步的语言身份组，以及是否具备管理权限。这些身份组信息仅在命令执行时即时读取，**不会写入数据库，也不做任何持久化存储**。本应用不跟踪成员加入、退出或在线状态，不收集所在服务器以外的成员数据。

本应用不收集用户 IP 地址，不使用 Cookie，不进行用户画像，不投放广告。

## 数据的使用方式

上述数据仅用于实现本应用的功能：

- 判定用户可获得的凭证数量与有效天数，并据此向关联服务发放授权
- 记录与展示用户的验证状态，支持用户自助查询与更换凭证
- 为服务器助力者发放对应的身份组奖励
- 同步用户的语言身份组
- 限制凭证更换频率与每日查询次数，防止服务被滥用
- 处理赞助申请，并按管理需要留存操作记录

## 数据的存储位置

全部数据存储在维护者自托管服务器的本地 SQLite 数据库中，不对任何第三方开放，不用于广告、分析或用户画像。

审计日志与运行日志仅写入维护者自有服务器的本地日志文件，其中可能包含 Discord 用户 ID 与用户名。

## 数据的对外传输

本应用在提供功能时，会向关联的 Final Fantasy XIV 授权服务发送必要的授权信息：

- 发放或撤销授权时，发送用户提交的账号凭证与授权时长

除上述为实现功能所必需的请求外，本应用不会把数据提供给任何第三方，也不会出售、出租或以其他方式交易用户数据。

本应用运行在 Discord 平台之上，Discord 自身对数据的处理适用 Discord 的隐私政策，不在本政策的覆盖范围内。

## 数据保留与删除

数据在用户使用服务期间保留。应用不会自动过期清理历史记录。

用户可以随时联系服务器管理员删除自己的全部记录，包括 Discord 用户 ID、用户名、语言偏好、游戏账号凭证、赞助申请资料与相关计数记录。删除后，与该用户关联的服务授权会一并撤销，需要重新验证才能恢复。
