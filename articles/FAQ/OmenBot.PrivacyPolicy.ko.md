최종 업데이트: 2026년 2월 20일

본 개인정보 처리방침은 OmenBot(Discord 애플리케이션 ID `1262631779316269116`, 이하 "본 앱")이 서비스를 제공하는 과정에서 어떤 데이터를 수집하고, 이를 어떻게 사용하며, 어디에 저장하는지, 그리고 이용자가 자신의 데이터를 어떻게 관리할 수 있는지를 설명합니다.

본 앱은 Daily Routines 개발자가 직접 호스팅하고 유지 관리합니다. 개발자 자신의 Discord 서버에서만 동작하며, 다이렉트 메시지의 애플리케이션 명령을 통해 이용자에게 서비스를 제공합니다.

## 수집하는 데이터

본 앱은 Discord 메시지 내용을 읽지 않고 저장하지 않습니다. 모든 데이터는 이용자가 애플리케이션 명령을 실행할 때 직접 제출한 정보와, Discord가 상호작용과 함께 전달하는 식별 정보에서 비롯됩니다.

| 데이터 | 설명 |
| --- | --- |
| Discord 사용자 ID | 모든 로컬 기록의 기본 키로, 자격 증명과 언어 설정을 특정 이용자에게 귀속시키는 데 사용합니다 |
| Discord 사용자 이름 | 관리 명령에서의 식별과 심사 기록 표시에 사용합니다. 사용자 이름은 검증 또는 제출 시마다 갱신되므로 항상 최신 이름입니다 |
| 언어 설정 | 이용자가 `/language` 로 선택한 인터페이스 언어 |
| 게임 계정 자격 증명 | 이용자가 `/verify` 로 제출한 파이널 판타지 XIV 계정 식별자로, 연동 서비스에 라이선스를 발급하는 데 사용합니다 |
| 자격 증명 시간 정보 | 자격 증명의 검증 시각, 만료 시각, 다음 검증 시각 |
| 자격 증명 변경 쿨다운 | 가장 최근의 자격 증명 변경 시각으로, 변경 빈도를 제한하는 데 사용합니다 |
| 일일 조회 횟수 | `/query-cid` 의 당일 호출 횟수로, 속도 제한에 사용합니다 |
| 후원 신청 데이터 | 이용자가 `/verify` 로 후원 신청 시 작성한 작성자명, 플랫폼명, 주문 번호, 스크린샷 링크, 그리고 심사 상태와 처리 결과 |
| 감사 로그 | 관리 작업과 서비스 이벤트의 기록으로, 작업자의 Discord 사용자 ID, 사용자 이름, 작업 내용을 포함합니다 |

서버 멤버 역할에 대하여: 본 앱은 "서버 멤버" 특권 인텐트를 신청했으며, 그 목적은 이용자가 서버에서 보유한 역할을 읽어 발급 가능한 자격 증명의 개수와 유효 기간, 서버 부스터 여부, 동기화해야 할 언어 역할, 관리 권한 보유 여부를 판정하는 것입니다. 이러한 역할 정보는 명령 실행 시점에 즉시 읽을 뿐이며, **데이터베이스에 기록되지 않고 어떤 형태로도 영구 저장되지 않습니다**. 본 앱은 멤버의 참가, 퇴장, 접속 상태를 추적하지 않으며, 자체 서버 이외의 멤버 데이터를 수집하지 않습니다.

본 앱은 IP 주소를 수집하지 않고, 쿠키를 사용하지 않으며, 이용자 프로파일링을 하지 않고, 광고를 게재하지 않습니다.

## 데이터의 사용 목적

위 데이터는 본 앱의 기능을 구현하기 위해서만 사용합니다.

- 이용자가 받을 수 있는 자격 증명의 개수와 유효 일수를 판정하고, 그에 따라 연동 서비스에 라이선스를 발급
- 검증 상태를 기록하고 표시하여 이용자가 직접 확인하고 자격 증명을 변경할 수 있도록 지원
- 서버 부스터에게 해당 역할 보상을 지급
- 이용자의 언어 역할을 동기화
- 자격 증명 변경 빈도와 일일 조회 횟수를 제한하여 서비스 남용을 방지
- 후원 신청을 처리하고 관리에 필요한 작업 기록을 보관

## 데이터의 저장 위치

모든 데이터는 유지 관리자가 직접 호스팅하는 서버의 로컬 SQLite 데이터베이스에 저장됩니다. 어떠한 제3자에게도 공개되지 않으며, 광고, 분석, 프로파일링에 사용되지 않습니다.

감사 로그와 실행 로그는 유지 관리자 자신의 서버에 있는 로컬 로그 파일에만 기록되며, Discord 사용자 ID와 사용자 이름을 포함할 수 있습니다.

## 데이터의 외부 전송

본 앱은 기능을 제공하기 위해 연동된 파이널 판타지 XIV 라이선스 서비스로 필요한 라이선스 정보를 전송합니다.

- 라이선스를 발급하거나 취소할 때, 이용자가 제출한 계정 자격 증명과 유효 기간

위의 기능 구현에 반드시 필요한 요청을 제외하고, 본 앱은 데이터를 제3자에게 제공하지 않으며, 이용자 데이터를 판매, 대여 또는 그 밖의 방식으로 거래하지 않습니다.

본 앱은 Discord 플랫폼 위에서 동작합니다. Discord 자체의 데이터 처리에는 Discord의 개인정보 처리방침이 적용되며, 본 방침의 적용 범위에 포함되지 않습니다.

## 데이터 보관과 삭제

데이터는 이용자가 서비스를 이용하는 동안 보관됩니다. 본 앱이 과거 기록을 자동으로 정리하지는 않습니다.

이용자는 언제든지 서버 관리자에게 연락하여 자신의 모든 기록(Discord 사용자 ID, 사용자 이름, 언어 설정, 게임 계정 자격 증명, 후원 신청 데이터, 관련 카운터)의 삭제를 요청할 수 있습니다. 삭제 후에는 해당 이용자에게 연결된 서비스 라이선스도 함께 취소되므로, 복구하려면 다시 검증해야 합니다.
