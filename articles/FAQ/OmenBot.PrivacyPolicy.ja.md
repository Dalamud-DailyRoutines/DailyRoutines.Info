---
title: OmenBot プライバシーポリシー
---

最終更新：2026 年 2 月 20 日

本プライバシーポリシーは、OmenBot（Discord アプリケーション ID `1262631779316269116`、以下「本アプリ」）がサービスの提供にあたってどのようなデータを収集し、それをどのように利用し、どこに保存するのか、また利用者が自身のデータをどのように管理できるのかを説明するものです。

本アプリは Daily Routines の開発者が自らホストし、保守しています。開発者自身の Discord サーバー内でのみ動作し、ダイレクトメッセージ上のアプリケーションコマンドを通じて利用者にサービスを提供します。

## 収集するデータ

本アプリは Discord のメッセージ内容を一切読み取らず、保存しません。すべてのデータは、利用者がアプリケーションコマンドを実行した際に自ら送信した情報、および Discord がインタラクションとともに渡す識別情報に由来します。

| データ | 内容 |
| --- | --- |
| Discord ユーザー ID | ローカル記録すべての主キーであり、資格情報と言語設定を特定の利用者に紐づけるために使用します |
| Discord ユーザー名 | 管理コマンドでの識別と、審査記録の表示に使用します。ユーザー名は検証または申請のたびに更新されるため、常に最新の名称となります |
| 言語設定 | 利用者が `/language` で選択したインターフェース言語 |
| ゲームアカウントの資格情報 | 利用者が `/verify` で送信したファイナルファンタジー XIV のアカウント識別子。連携サービスへのライセンス発行に使用します |
| 資格情報の時刻情報 | 資格情報の検証日時、有効期限、次回検証日時 |
| 資格情報変更のクールダウン | 直近の資格情報変更日時。変更頻度を制限するために使用します |
| 1 日あたりのクエリ回数 | `/query-cid` の当日の呼び出し回数。レート制限に使用します |
| スポンサー申請データ | 利用者が `/verify` でスポンサー申請時に記入した作者名、プラットフォーム名、注文番号、スクリーンショットのリンク、および審査状況と処理結果 |
| 監査ログ | 管理操作とサービスイベントの記録。操作者の Discord ユーザー ID、ユーザー名、操作内容を含みます |

サーバーメンバーのロールについて：本アプリは「サーバーメンバー」特権インテントを申請しており、その目的は利用者がサーバー内で持つロールを読み取り、付与できる資格情報の数と有効期間、サーバーブースターであるかどうか、同期すべき言語ロール、および管理権限の有無を判定することです。これらのロール情報はコマンド実行時にその場で読み取るだけで、**データベースに書き込まれることはなく、いかなる形でも永続化されません**。本アプリはメンバーの参加・退出・オンライン状態を追跡せず、自サーバー以外のメンバーデータを収集しません。

本アプリは IP アドレスを収集せず、Cookie を使用せず、利用者プロファイリングを行わず、広告を配信しません。

## データの利用目的

上記のデータは、本アプリの機能を実現するためにのみ使用します。

- 利用者が受け取れる資格情報の数と有効日数を判定し、それに基づいて連携サービスへライセンスを発行する
- 検証状況を記録・表示し、利用者自身による確認と資格情報の変更を可能にする
- サーバーブースターに対応するロール報酬を付与する
- 利用者の言語ロールを同期する
- 資格情報の変更頻度と 1 日あたりのクエリ回数を制限し、サービスの濫用を防ぐ
- スポンサー申請を処理し、管理上必要な操作記録を保持する

## データの保存場所

すべてのデータは、保守者が自らホストするサーバー上のローカル SQLite データベースに保存されます。第三者に開示されることはなく、広告・分析・プロファイリングに利用されることもありません。

監査ログおよび実行ログは、保守者自身のサーバー上のローカルログファイルにのみ書き込まれ、Discord ユーザー ID とユーザー名を含む場合があります。

## データの外部送信

本アプリは機能の提供にあたり、連携するファイナルファンタジー XIV のライセンスサービスへ必要なライセンス情報を送信します。

- ライセンスの発行または取り消し時に、利用者が送信したアカウントの資格情報と有効期間

上記の機能実現に必要不可欠なリクエストを除き、本アプリがデータを第三者へ提供することはなく、利用者データを販売・貸与・その他の方法で取引することもありません。

本アプリは Discord プラットフォーム上で動作します。Discord 自身によるデータの取り扱いには Discord のプライバシーポリシーが適用され、本ポリシーの対象外です。

## データの保持と削除

データは、利用者がサービスを利用している間、保持されます。本アプリが過去の記録を自動的に削除することはありません。

利用者はいつでもサーバー管理者に連絡することで、自身のすべての記録（Discord ユーザー ID、ユーザー名、言語設定、ゲームアカウントの資格情報、スポンサー申請データ、および関連するカウンター）の削除を依頼できます。削除後は、その利用者に紐づくサービスのライセンスも取り消されるため、復旧には再度の検証が必要です。
